---
title: Rust API (rustdoc)
description: Where to read the Lamina PDF crate's API documentation.
---

Lamina PDF's Rust crates aren't on crates.io yet, so docs.rs has no copy of their documentation. Build it on your own machine from a checkout of Lamina PDF:

```sh
cargo doc --workspace --no-deps --all-features --open
```

The command opens the docs in your browser. Every public item of every crate is documented.

Start with the `laminapdf` crate. It's the one to depend on. It wraps the core crates and holds `Document`, `Builder`, `Error`, `Warning`, jobs and `CancelToken`. The core crates under it (`laminapdf-syntax`, `laminapdf-cos`, `laminapdf-model`, `laminapdf-ops`, `laminapdf-save`, `laminapdf-content`, `laminapdf-text`, `laminapdf-build`) are documented the same way.

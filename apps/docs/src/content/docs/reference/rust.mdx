docs.rs builds the API documentation of every Lamina PDF crate on crates.io. Start with [`laminapdf` on docs.rs](https://docs.rs/laminapdf/0.2.0-alpha.2/laminapdf/), the crate to depend on. It wraps the core crates and holds `Document`, `Builder`, `Error`, `Warning`, jobs and `CancelToken`.

- [`laminapdf-cos`](https://docs.rs/laminapdf-cos/0.2.0-alpha.2/laminapdf_cos/)
- [`laminapdf-model`](https://docs.rs/laminapdf-model/0.2.0-alpha.2/laminapdf_model/)
- [`laminapdf-ops`](https://docs.rs/laminapdf-ops/0.2.0-alpha.2/laminapdf_ops/)
- [`laminapdf-save`](https://docs.rs/laminapdf-save/0.2.0-alpha.2/laminapdf_save/)
- [`laminapdf-content`](https://docs.rs/laminapdf-content/0.2.0-alpha.2/laminapdf_content/)
- [`laminapdf-text`](https://docs.rs/laminapdf-text/0.2.0-alpha.2/laminapdf_text/)
- [`laminapdf-build`](https://docs.rs/laminapdf-build/0.2.0-alpha.2/laminapdf_build/)

[Install](/install/#every-published-package) lists every crate, with its page on crates.io.

## Build the docs yourself

To read the docs of a change before it's released, build them from a checkout of Lamina PDF:

```sh
cargo doc --workspace --no-deps --all-features --open
```

The command opens the docs in your browser. Every public item of every crate is documented.

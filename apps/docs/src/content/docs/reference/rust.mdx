---
title: Rust API (rustdoc)
description: Where to read the lamina crate's API documentation.
---

lamina's Rust crates aren't on crates.io yet, so docs.rs has no copy of their documentation. Build it on your own machine from a checkout of lamina:

```sh
cargo doc --workspace --no-deps --all-features --open
```

The command opens the docs in your browser. Every public item of every crate is documented.

Start with the `lamina` crate. It's the one to depend on, and it wraps the core crates: `Document`, `Builder`, `Error`, `Warning`, jobs and `CancelToken`. The core crates under it (`lamina-syntax`, `lamina-cos`, `lamina-model`, `lamina-ops`, `lamina-save`, `lamina-content`, `lamina-text`, `lamina-build`) are documented the same way.

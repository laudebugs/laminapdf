Every Lamina PDF crate on crates.io has its API documentation on docs.rs. Most programs depend on one crate, [`laminapdf`](https://docs.rs/laminapdf/{{version}}/laminapdf/), so start there. It holds `Document`, `Builder`, `Error`, `Warning`, the jobs and `CancelToken`, and it wraps the other crates.

## The other crates

You need these only to reach something `laminapdf` doesn't wrap, or to read how a part works:

- [`laminapdf-syntax`](https://docs.rs/laminapdf-syntax/{{version}}/laminapdf_syntax/) reads and writes PDF objects, and holds the error codes.
- [`laminapdf-cos`](https://docs.rs/laminapdf-cos/{{version}}/laminapdf_cos/) opens a file, repairs a broken one, and keeps your edits apart from the bytes you opened.
- [`laminapdf-model`](https://docs.rs/laminapdf-model/{{version}}/laminapdf_model/) gives typed views: pages, the outline, metadata and the structure tree.
- [`laminapdf-ops`](https://docs.rs/laminapdf-ops/{{version}}/laminapdf_ops/) holds the edits, their transactions, and undo and redo.
- [`laminapdf-save`](https://docs.rs/laminapdf-save/{{version}}/laminapdf_save/) chooses how to save and writes the file.
- [`laminapdf-content`](https://docs.rs/laminapdf-content/{{version}}/laminapdf_content/) reads a page's drawing instructions.
- [`laminapdf-text`](https://docs.rs/laminapdf-text/{{version}}/laminapdf_text/) loads, shapes and embeds fonts, lays out text and reads text back.
- [`laminapdf-build`](https://docs.rs/laminapdf-build/{{version}}/laminapdf_build/) builds new pages and documents.
- [`laminapdf-extract`](https://docs.rs/laminapdf-extract/{{version}}/laminapdf_extract/) turns pages into blocks, tables, Markdown and chunks.
- [`laminapdf-source`](https://docs.rs/laminapdf-source/{{version}}/laminapdf_source/) reads files from disk or in ranges, as they download.
- [`laminapdf-render`](https://docs.rs/laminapdf-render/{{version}}/laminapdf_render/) defines how a renderer draws pages into pixels.
- [`laminapdf-render-pdfium`](https://docs.rs/laminapdf-render-pdfium/{{version}}/laminapdf_render_pdfium/) draws pages with PDFium.

[Install](/install/#every-published-package) lists every crate with its page on crates.io.

## Build the docs yourself

To read the docs of a change that isn't released yet, build them from a checkout of Lamina PDF. This command builds every crate's docs and opens them in your browser:

```sh
cargo doc --workspace --no-deps --all-features --open
```

For how the packages version together and what an upgrade can change, read the [stability policy](/reference/stability/) next.

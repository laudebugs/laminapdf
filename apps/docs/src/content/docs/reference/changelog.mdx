Every Lamina PDF package shares one version, so each entry covers all of them, from the Rust crates to `@laminapdf/sdk` and the viewer. Versions from `0.2.0-alpha.2` on are on npm and crates.io; earlier ones were never published.

Each entry lists its changes under two headings:

- **Minor Changes** holds new features and every breaking change. Before version 1.0, a breaking change raises the minor version (`0.2` to `0.3`), as the [stability policy](/reference/stability/) explains. Read this list first when you upgrade: a breaking change's entry says what to change in your code.
- **Patch Changes** holds fixes, which keep your code working.

For example, to move from `0.2.0-alpha.4` to `0.2.0-alpha.6`, read the entries for `alpha.5` and `alpha.6`. Alphas promise nothing to each other, so read both headings of each entry.

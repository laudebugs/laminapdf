Every Lamina PDF package shares one version, so each entry covers all of them: the crates, `@laminapdf/sdk`, `@laminapdf/wasm`, the renderers and `@laminapdf/viewer`. Breaking changes come first, under **Minor Changes**, as the [stability policy](/reference/stability/) explains. Versions from `0.2.0-alpha.2` on are on npm and crates.io; earlier ones were never published.

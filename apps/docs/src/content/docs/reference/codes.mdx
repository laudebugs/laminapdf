Every error and warning Lamina PDF raises has a code, such as `wrong-password`, and the code is the same in Rust, WebAssembly and `@laminapdf/sdk`. Match on the code, not the message: messages can change, but a code keeps its meaning in every version.

The tables below group the codes by the part of Lamina PDF that raises them. Each row gives the code's kind, one of nine broad groups you can match on instead, then what happened and what to do. Each code links to its own page, which says when the code happens, why, how to fix it, and what its `data` holds. To learn how to catch errors and read warnings in your code, see [errors and warnings](/concepts/errors-and-warnings/).

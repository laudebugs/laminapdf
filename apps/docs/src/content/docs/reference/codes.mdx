Every error and warning lamina raises, in Rust, in WebAssembly and in `@laminapdf/pdf`, has one of these codes. The tables below are read from `fixtures/codes.json` when this site is built: the same file `cargo xtask gen codes` generates the Rust enums and the TypeScript unions from. Each code links to its page on this site, which explains when it happens, why, how to fix it and what its `data` holds. See [Errors and warnings](/guides/errors-and-warnings/) for how to handle them.

Lamina PDF creates, reads, edits and saves PDFs. One Rust core does the work, and it runs natively and as WebAssembly in browsers, Node, Deno, Bun and Cloudflare Workers. It's for apps that make documents, such as invoices, reports and tickets, and for apps that open documents other people send.

- **[`laminapdf`](https://crates.io/crates/laminapdf)** on crates.io is the Rust crate. Its [API reference](/reference/rust/) is on docs.rs.
- **[`@laminapdf/sdk`](https://www.npmjs.com/package/@laminapdf/sdk)** on npm is the TypeScript API over the WebAssembly build. After one `await init()`, every call is synchronous, and the API is the same in every runtime. Its [API reference](/reference/sdk/readme/) is on this site.

:::note[Versions]
Install the version these docs describe: `npm install @laminapdf/sdk@{{version}}` and `cargo add laminapdf@{{version}}`. From `0.2.0` on, both follow SemVer, so later releases in the same `0.x` line need no change to your code. [Install](/install/) lists every published package.
:::

## What works today

| Area | What you get | Guide |
| --- | --- | --- |
| Generate | Pages, text with shaping, bidi and line breaking, embedded and subset fonts, the standard 14, vectors, colour, images, tagged PDF | [Fonts and text](/guides/fonts-and-text/), [Images and vectors](/guides/images-and-vectors/) |
| Navigate | Links, named destinations, outlines, page labels, Info and XMP metadata | [Links, outlines and metadata](/guides/links-outlines-and-metadata/) |
| Edit | Ops in transactions, undo and redo, incremental or full saves that respect signatures | [Edit a PDF](/guides/edit-a-pdf/), [Save a PDF](/guides/save-a-pdf/) |
| Extract | Text, Markdown and JSON in reading order, with tables, a box for every block and chunks for retrieval | [Extract text and Markdown](/guides/extract-text/) |
| Read safely | Repair of damaged files as warnings, resource limits, strict mode, passwords | [Open password-protected files](/guides/password-protected-files/), [Open files you don't trust](/guides/untrusted-files/) |
| Errors | One coded error and warning shape on every surface | [Errors and warnings](/concepts/errors-and-warnings/) |

Every code block on this site is a tested example file, so the code you see is the code that runs. Each example writes the same bytes in Rust and in every JavaScript runtime.

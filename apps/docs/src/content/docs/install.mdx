Lamina PDF is published to npm as [`@laminapdf/sdk`](https://www.npmjs.com/package/@laminapdf/sdk) and to crates.io as [`laminapdf`](https://crates.io/crates/laminapdf). Both follow SemVer from `0.2.0` on: a breaking change raises the minor version (`0.2` to `0.3`), so an upgrade within one `0.x` line, such as `0.2.0` to `0.2.1`, needs no change to your code.

## TypeScript: `@laminapdf/sdk`

Install the version these docs describe:

```sh
npm install @laminapdf/sdk@{{version}}
```

Without a version, `npm install @laminapdf/sdk` installs the newest release. pnpm, Yarn and Bun take the same name (`pnpm add @laminapdf/sdk@{{version}}`), and Deno takes `npm:@laminapdf/sdk@{{version}}`. The package brings [`@laminapdf/wasm`](https://www.npmjs.com/package/@laminapdf/wasm), its WebAssembly modules, as a dependency.

The package is ESM only. It has one entry per runtime (the `workerd`, `deno`, `browser`, `node` and `default` export conditions), and each entry loads the `.wasm` its own way. The [quick starts](/quick-start/browser/) show each one.

## Rust: `laminapdf`

Add the crate at the version these docs describe:

```sh
cargo add laminapdf@{{version}}
```

The command writes `laminapdf = "{{version}}"` to `Cargo.toml`, and Cargo reads it as this release or a later one in the same `0.x` line, which the [stability policy](/reference/stability/) promises needs no change to your code.

The default features start with `text`: fonts and text, which includes the builder and text extraction. Four more are on by default: `markdown` (Markdown in, flowing pages out), `document` (JSON documents in, flowing pages out), `reflow` (a tagged document's text in reading order, for reader mode) and `saslprep` (passwords for AES-256 files). For reading and editing only, add `--no-default-features`, then turn on what you need: `build` for the builder without text, `extract` for text extraction alone. `explain`, off by default, gives each code's page as text.

## The command-line tool

The `laminapdf` command does the common jobs from a terminal or a script, without a Node or Rust project: describe, check, extract, render and build PDFs. Homebrew installs it with `brew install laudebugs/tap/laminapdf`; [install the command-line tool](/cli/install/) has npm and downloads for macOS, Linux and Windows.

## Try a change before it's released

An unreleased change is only in the repository, so build the packages from a checkout. You need Rust (the toolchain in `rust-toolchain.toml` installs itself), Node 22 or newer and pnpm:

```sh
pnpm install
cargo xtask wasm      # builds packages/wasm/dist/ and packages/sdk/dist/, then tests them
```

Then run `pnpm pack` in `packages/wasm` and in `packages/sdk`, and install both `.tgz` files in one command: `@laminapdf/sdk` depends on `@laminapdf/wasm` at the same version, which the registry may not have yet. In Rust, use a path dependency: `laminapdf = { path = "../laminapdf/crates/laminapdf" }`.

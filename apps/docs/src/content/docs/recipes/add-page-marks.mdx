You'll mark every page of a report: a faint CONFIDENTIAL across the page, the file's name and the date at the top, "Page 1 of 2" at the bottom, and a Bates number in the corner. You need this for a legal production, a review copy, or a stamp your editor's menu applies to a whole document.

Like [added text](/recipes/add-text/), a mark becomes part of the page: it prints and every reader draws it. One edit marks many pages, so you name the pages, counted from 0:

The result is the original bytes, unchanged, followed by one revision. The watermark sits in a layer, so a reader's layers panel can switch it off.

## How it works

- **Watermarks and backgrounds:** a watermark is drawn in front of each page's content and a background behind it. Each shows text, centred on the page and turned by `angle` degrees counterclockwise, or an image: a watermark shows it whole inside most of the page, a background covers the page with it. Add an image's bytes with `addBlob` first.
- **Fields:** a header or footer slot's text may hold `{page}`, `{pages}`, `{label}` (the page's label, else its number), `{date}` and `{file}`. You give `{date}` and `{file}` as text, so the same call writes the same bytes everywhere. `{{` and `}}` are braces. The fields are filled when you apply the edit, so a page you move later keeps its number: apply the mark again with `updatePageMark` to number it afresh.
- **Slots:** a header and footer has six slots in the order top left, centre, right, then bottom left, centre, right. Each is one line, left, centred or right aligned, between the margins (36 points unless you say otherwise). The three slots on an edge overlap, so a long text runs past its third of the page.
- **Bates numbers:** `start` is the first page's number, and each page after it counts one more, in the order you name the pages. To number a second file where the first ended, apply the edit to it with the next `start`. A number wider than `digits` is not cut.
- **Fonts:** as for added text, `fonts` is the font, then its fallbacks, in Helvetica when absent. Text in a font you give by its bytes is embedded once for each page whose text differs, which a long document's page numbers make a page each. Helvetica, Times and Courier need no bytes.
- **Tagging:** in a tagged file every mark is an artifact: a watermark, a background, a header, a footer or a Bates number. Screen readers skip it, and it joins no structure.
- **Finding them again:** Lamina PDF stores each mark's ID and what it says with the mark. After a save and a reopen, `content.pageMarks(index)` lists a page's marks, `content.updatePageMark(pages, id, mark, modified)` replaces one on the pages you name, and `content.deletePageMark(pages, id)` takes it off. An [incremental save](/reference/glossary/#incremental-save) keeps the earlier revisions, and the mark stays in them.

## What to change

- **Opacity and angle:** `opacity` is from 0 to 1 and `angle` from -360 to 360 degrees.
- **A layer a reader can hide:** `hideable: true` puts the mark in an optional content group, so a reader's layers panel can switch it off. Deleting the mark from the last page that has it takes the layer out of the file. A PDF/A-1 file can't hold layers.
- **A different mark of the same kind:** `updatePageMark` takes the new mark as `{ watermark }`, `{ background }`, `{ headerFooter }` or `{ bates }`; a mark of another kind fails with [`invalid-op`](/reference/codes/invalid-op/), and a page without the mark with [`unknown-page-mark`](/reference/codes/unknown-page-mark/).
- **Colour and margins:** `color` is a gray, RGB or CMYK array, and `margins` is `{ top, right, bottom, left }` in points.
- **A signed file:** like every change to a page, a mark breaks a certified file's signature, and an approval-signed file takes it in a revision after the signature.
- **A PDF/A file:** Helvetica, Times and Courier aren't embedded, which PDF/A forbids, so `doc.plan()` warns with [`pdfa-font-not-embedded`](/reference/codes/pdfa-font-not-embedded/). Give the mark a font by its bytes instead.

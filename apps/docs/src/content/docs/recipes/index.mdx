Each recipe is a complete program to copy: what it makes, the code, how it works and what to change. Pick the one closest to the document you need, and change it from there.

Most recipes exist twice, in Rust and in TypeScript, and both write exactly the same bytes. Lamina PDF's tests check that on every change, in Rust and in every JavaScript runtime: Node, Chromium, Firefox, WebKit, Deno, Bun and workerd. Each recipe shows the tested code, and its reference PDF is the file that code writes. To test your own PDFs the same way, see [Test the PDFs you generate](/guides/test-generated-pdfs/).

To run a Rust recipe from a checkout of Lamina PDF, use `cargo run -p laminapdf --example <name>`. Its header comment lists the arguments it takes, such as the font or image files it reads.

- [Turn photos into a PDF](/recipes/images-to-pdf/): one page per photo, fitted on A4, each JPEG embedded as it is.
- [Element flow](/recipes/element-flow/): a report whose parts each start below the one before, over two pages.
- [Turn Markdown into a PDF](/recipes/markdown-to-pdf/): a report written in Markdown, from the command line, TypeScript or Rust.
- [Fill an invoice from JSON](/recipes/invoice-from-json/): a JSON template filled from data, its line items repeated into a table across pages.
- [Links and outlines](/recipes/links-and-outlines/): links, an outline and page labels.

## Edit a PDF

- [Generate, then edit](/recipes/generate-then-edit/): open a file's bytes, change its metadata and save incrementally.
- [Edit the metadata](/recipes/edit-metadata/): a title, authors and keywords in both copies a PDF keeps, checked before the save.
- [Choose how a PDF opens](/recipes/set-initial-view/): the page and zoom, the panel beside the page and the title in the window.
- [Edit the bookmarks](/recipes/edit-bookmarks/): add, move and style bookmarks, and name places links jump to.
- [Record your own metadata](/recipes/edit-xmp/): properties of your own in the XMP metadata, in a PDF/A file that stays valid.
- [Organise pages](/recipes/organise-pages/): delete, move, insert and rotate pages in one edit, with the bookmarks and links that pointed at a deleted page sent on.
- [Duplicate pages](/recipes/duplicate-pages/): copy a page so the copy has form fields, annotations and tags of its own.
- [Copy pages between PDFs](/recipes/copy-pages/): copy pages in from another file, replace a page, or make a new PDF from some pages.

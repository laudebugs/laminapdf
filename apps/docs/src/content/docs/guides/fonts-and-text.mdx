Text needs the text module: `init({ text: true })` or `loadText()` in TypeScript, and the default `text` feature in Rust.

## Two kinds of font

- **The standard 14** (`Font.standard("Helvetica")`, `Standard14::Helvetica` in Rust) need no bytes and aren't embedded. They cover Latin text only, without shaping. Text they can't encode fails with `missing-glyph`. More than 37 distinct letters outside WinAnsi fails with `encoding-full`.
- **Your own fonts** (`Font.fromBytes(bytes)`: TrueType, OpenType or a collection) are shaped with HarfRust and **subset** to the glyphs you draw. They're embedded as Type 0 fonts with `/W` widths and a ToUnicode CMap, so the text can be extracted again. Equal fonts are embedded once per document, however many `Font` objects name them.

**`fsType`:** a font whose licence bits forbid embedding (restricted, or bitmap only) fails with `font-not-embeddable`. In Rust, `EmbedPolicy::Override` embeds it anyway, if you hold the rights. A font marked "no subsetting" is embedded whole.

## Scripts, direction and line breaking

`surface.text(str, { font, size, at })` draws one shaped line, with `at[1]` its baseline. `surface.textBox(str, { font, size, box, direction, align })` breaks a paragraph at UAX #14 opportunities to fit its box, lays out each line in visual order (UAX #9 bidi), and reports `overflow`.

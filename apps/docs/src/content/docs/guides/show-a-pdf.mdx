You'll put a PDF on your page that people can scroll and zoom, with text they can select and links within the document they can follow. The viewer draws only the pages near the scroll position, so a 1,000-page file scrolls as smoothly as a short one.

:::caution[Preview]
`@laminapdf/viewer` is a preview. It is the core of [the Lamina PDF reader](https://app.laminapdf.com), and its API can still change between releases while the reader grows.
:::

Install the viewer and the PDFium build it draws with:

```sh
npm install @laminapdf/viewer @embedpdf/pdfium@2.15.1
```

This example shows a file the user picked, in a container on your page:

<Snippet file="packages/viewer/examples/show-a-pdf.ts" />

Call it with an element that has a height, the file from an `<input type="file">` or a drop, and the address your bundler serves PDFium's WebAssembly at:

```ts
using shown = await showPdf(container, file, pdfiumWasm);
```

## What runs where

The viewer splits the work between your page and a Web Worker, one per document:

- **The Web Worker** opens the file with Lamina PDF and draws pages with PDFium. A long page never blocks your page's scrolling or typing.
- **Your page** holds the view: a shell for each page near the scroll position, the canvases they paint into, and the text and link layers over them.

The file stays in the Web Worker. A `File` is read there in slices, so the page never holds a copy of its bytes. To show a file from a server instead, pass `client.open` the file's address as `{ url }` where the example passes `file`. The Web Worker then reads it with HTTP range requests, fetching only the parts the visible pages need.

## Give the container a size

The viewer fills its container and scrolls inside it, so the container needs a height: a fixed one, or `flex: 1` in a column that fills the window. A container with no height shows nothing.

## Take it down

Dispose of what `showPdf` returns, with `using` or by calling `[Symbol.dispose]()`, when the PDF leaves the page. That stops its renders, frees its canvases and ends its Web Worker. A file that fails to open, a damaged or password-protected one, ends its Web Worker before `showPdf` throws.

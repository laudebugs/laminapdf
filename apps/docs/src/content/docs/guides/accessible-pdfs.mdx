This guide builds a report that screen-reader users can read, which you need whenever a document has to meet accessibility law or a client's accessibility policy.

## What PDF/UA asks for

PDF/UA-1 (ISO 14289-1, "Universal Accessibility") is the standard for accessible PDF. A PDF/UA file is tagged: its structure tree says which content is a heading, a paragraph, a list, a table or a figure, and in what order to read it. Everything else, such as running headers and decorative rules, is marked as an artifact, which assistive technology skips. The file also needs a title, a language, alternate text for every figure, a description for every link and embedded fonts that map each glyph to characters.

Turn the profile on with one option. Then `finish()` checks the rules a program can check and fails with a coded error for the first one the document breaks:

| Rule | Error |
| --- | --- |
| The metadata has a title | [`missing-title`](/reference/codes/) |
| The document has a language (`lang`) | `missing-lang` |
| Everything drawn is tagged or an artifact | `untagged-content` |
| Every figure has alternate text | `missing-alt-text` |
| Headings start at `H1` and skip no level going down | `heading-level-skipped` |
| Table cells sit in rows, rows in tables, list items in lists | `invalid-structure-nesting` |
| Every link has a `Link` element and a description | `link-without-structure`, `link-without-contents` |
| Every font is embedded (no standard 14 font) | `font-not-embedded` |
| Every glyph maps to Unicode | `glyph-without-unicode` |

The builder writes the rest for you. It puts the PDF/UA identifier in the document's XMP metadata, the XML packet in the file that describes it. It also asks viewers to show the title instead of the file name, and orders links by the structure.

## What a program can't check

About half of PDF/UA's requirements need a person. lamina can check that a figure has alternate text, but not that the text describes the figure. It can check that headings go down one level at a time, but not that the right text is a heading, that the reading order makes sense or that colour isn't the only way the document conveys meaning. Read the document with a screen reader before you publish it.

## How lamina checks its own output

Every example on this site that claims PDF/UA-1 is validated each night with veraPDF, the open-source validator the PDF Association backs. Any violation fails the run. You can run the same check locally with `cargo xtask verapdf` from a clone of the repository.

To make a document both accessible and archival, add a PDF/A profile next to `PDF/UA-1`: see [Archival PDFs](/guides/archival-pdfs/).

Lamina PDF reads files encrypted with the standard security handler: RC4 (R2–R4), AES-128 (R4) and AES-256 (R5, R6), including crypt filters and cleartext metadata. Strings and streams are decrypted as the file loads.

- **Pass the password** with `Document.open(bytes, { password })`. It's tried as the user password, then as the owner password.
- **Unicode passwords:** the password is tried as you give it, then in NFKC form after `wrong-password`. So R2–R4 passwords reach the core unchanged, and R5/R6 passwords match SASLprep's normalisation.
- **No password, or the wrong one,** fails with `password-required` or `wrong-password`. Ask the user and try again: nothing else has changed.
- **Saving:** an encrypted file saves incrementally, or as a plaintext full rewrite with `removeEncryption: true` (see [saving](/guides/open-edit-and-save/#saving)). Writing encrypted files is planned.

You'll write `hello.pdf`, one A4 page that says "Hello, world!", from a short Node script. Once lamina is built, it takes about five minutes.

## Before you start

lamina isn't on npm yet, so you install it from a build of the repository. You need Node 24, pnpm, and Rust for that build; [Install](/install/) covers the details. Build the packages once, in your checkout of lamina:

```sh
pnpm install
cargo xtask wasm
(cd packages/wasm && pnpm pack) && (cd packages/sdk && pnpm pack)
```

The last line packs `@laminapdf/wasm` and `@laminapdf/sdk` into two `.tgz` files, which your project installs.

## Make a project

Create a folder next to your checkout and install both packages in it:

```sh
mkdir hello-pdf && cd hello-pdf
npm init -y && npm pkg set type=module
npm install ../lamina/packages/wasm/laminapdf-wasm-*.tgz ../lamina/packages/sdk/laminapdf-sdk-*.tgz
```

## Run it

```sh
node hello.ts
```

Node 24 runs the TypeScript file as it is. Open `hello.pdf` in any PDF viewer: one page, with "Hello, world!" near its top-left corner.

## What happened

`init` loaded lamina's WebAssembly module, after which every call is synchronous. The builder made an A4 page, drew the text on it and finished into a document, and `save` turned that document into bytes. `using` freed the builder and the document as soon as the function ended.

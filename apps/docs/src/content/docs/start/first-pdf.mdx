You'll write `hello.pdf`, one A4 page that says "Hello, world!", from a short Node script. Once Lamina PDF is built, it takes about five minutes.

## Before you start

Lamina PDF isn't on npm yet, so you install it from a build of the repository, which is private for now. You need access to it, Node 24.2 or newer, pnpm, and Rust; [Install](/install/) covers the details. Clone it into a folder named `laminapdf` (ask a maintainer for the URL), build the packages once, and pack them into one folder:

```sh
git clone <repository URL> laminapdf && cd laminapdf
pnpm install
cargo xtask wasm
(cd packages/wasm && pnpm pack --pack-destination ../../packs)
(cd packages/sdk && pnpm pack --pack-destination ../../packs)
```

The last two lines write `@laminapdf/wasm` and `@laminapdf/sdk` as `.tgz` files into `packs/`, which your project installs.

## Make a project

Leave the checkout, create a folder next to it and install both packages:

```sh
cd ..
mkdir hello-pdf && cd hello-pdf
npm init -y && npm pkg set type=module
npm install ../laminapdf/packs/*.tgz
```

## Run it

```sh
node hello.ts
```

Node runs the TypeScript file as it is. Open `hello.pdf` in any PDF viewer: one page, with "Hello, world!" near its top-left corner.

## What happened

`init({ text: true })` loaded Lamina PDF's text module, the one that draws fonts; after it, every call is synchronous. The builder made an A4 page, drew the text on it and finished into a document, `doc.save()` turned that document into bytes, and `save` wrote them to `hello.pdf`. `using` freed the builder and the document as soon as the function ended.

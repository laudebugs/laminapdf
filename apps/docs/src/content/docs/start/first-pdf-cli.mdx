You'll turn a short Markdown file into a tagged PDF with the `laminapdf` command, then check the PDF, read its text back and draw its page as an image. It takes about five minutes, and you need no Node or Rust project.

## Install the tool

On macOS and Linux, install it with Homebrew; anywhere npm runs, install it with npm:

```sh
brew install laudebugs/tap/laminapdf
```

```sh
npm install -g @laminapdf/cli@{{version}}
```

[Install the tool](/cli/install/) has downloads for every system and how to check them. Check that it runs:

## What happened

`build` read the Markdown, set it in Helvetica and Courier (two of the [standard 14 fonts](/reference/glossary/), which PDF viewers have), and wrote a tagged PDF with no creation date, so the same file always gives the same bytes. `info`, `check`, `extract` and `render` each opened that PDF and printed what they found.

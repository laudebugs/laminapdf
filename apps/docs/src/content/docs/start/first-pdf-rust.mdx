You'll write `hello.pdf`, one A4 page that says "Hello, world!", from a small Rust program. It takes about five minutes, most of it for the first build.

## Make a project

You need Rust 1.97 or newer. Create a project and add the `laminapdf` crate:

```sh
cargo new hello-pdf && cd hello-pdf
cargo add laminapdf@={{version}}
```

Lamina PDF is in alpha, so `=` pins the exact version these docs describe; a later alpha may change the API. [Install](/install/#rust-laminapdf) covers the crate's features.

## Run it

```sh
cargo run
```

The program writes `target/examples-out/hello.pdf`; `cargo run -- out` writes `out/hello.pdf` instead. Open it in any PDF viewer: one page, with "Hello, world!" near its top-left corner.

## What happened

`Builder` made an A4 page, and the page's surface drew the text in Helvetica, one of the [standard 14 fonts](/reference/glossary/) every PDF viewer has, so nothing was embedded. Points count from the page's top-left corner, and the text's `y` is its baseline. `finish` turned the builder into a document, and `save` turned the document into bytes.

`build` takes `BuildOptions`, which can fix the file ID, the producer and the creation date, so the same program writes the same bytes on every run. The examples on this site use that to check their output byte for byte.

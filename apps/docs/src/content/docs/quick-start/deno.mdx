In Deno, `@laminapdf/sdk` fetches each `.wasm` file from next to its own code (a `file:` URL), so reading files needs `--allow-read`.

This is how lamina's tests run every example in Deno. It reads each input with `Deno.readFile` and registers each example with `Deno.test`:

<Snippet file="packages/sdk/test/deno/examples.test.ts" />

The suite it runs, `runSuite`, calls `await init({ text: true })` once, then builds each example, such as [`hello`](/quick-start/node/), and checks that its bytes match the Rust version's.

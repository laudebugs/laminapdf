In Deno, `@laminapdf/sdk` fetches its `.wasm` files from next to its own code, through `file:` URLs. Reading them needs `--allow-read`, and writing `hello.pdf` needs `--allow-write`.

This app builds one A4 page that says "Hello, world!" and writes it to `hello.pdf`:

<Snippet file="packages/sdk/examples/quick-start/deno.ts" />

Save it as `hello.ts` and run it:

```sh
deno run --allow-read --allow-write hello.ts
```

lamina's tests run this app in Deno and check that it writes exactly the bytes of the Rust quick start.

Cloudflare Workers can't compile WebAssembly at run time. So Wrangler bundles the package's entry for Cloudflare Workers, which imports both `.wasm` files as `WebAssembly.Module`s. `init` instantiates them once per isolate.

This Cloudflare Worker returns a one-page letter at `/?name=…` and the 100-page report at `/report`. lamina's tests run it in workerd, Cloudflare's runtime:

<Snippet file="packages/sdk/examples/worker/src/index.ts" />

Its Wrangler configuration bundles the fonts as `Data` modules:

<Snippet file="packages/sdk/examples/worker/wrangler.toml" />

Run it locally from `packages/sdk` with `pnpm exec wrangler dev -c examples/worker/wrangler.toml`.

- **Errors the caller caused** (kind `input` or `limit`) become a `400` with the error's JSON. See [Errors and warnings](/guides/errors-and-warnings/).
- **Memory:** both functions free their builder and document as soon as the bytes are saved, because one isolate serves many requests.

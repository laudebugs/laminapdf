The `laminapdf` crate is the one to depend on: it wraps Lamina PDF's core crates in one API. Add it as a [path dependency](/install/#rust-laminapdf), then build a document. This is the `hello` example, which is tested on every change:

<Snippet file="crates/laminapdf/examples/hello.rs" />

Run it with `cargo run -p laminapdf --example hello`, which writes `target/examples-out/hello.pdf`.

- **Same input, same bytes:** the file ID, the producer and the dates are given, so the output never changes; see [how Lamina PDF thinks about a PDF](/concepts/how-lamina-thinks/#same-input-same-bytes).
- **Stopping a save:** `save` runs to the end. To let another thread stop it, pass a `CancelToken` to `save_with`, or call `save_job` for a job that you step through with a work budget.
- The [Rust API reference](/reference/rust/) documents every public item.

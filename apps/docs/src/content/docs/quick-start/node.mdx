In Node (22 or newer), `@laminapdf/sdk` reads its `.wasm` files from the `@laminapdf/wasm` package as bytes. Call `await init({ text: true })` once; after that, every call is synchronous.

This app builds one A4 page that says "Hello, world!" and writes it to `hello.pdf`:

<Snippet file="packages/sdk/examples/quick-start/node.ts" />

Save it as `hello.ts` next to your `package.json` and run it. Node 24 runs TypeScript files as they are:

```sh
node hello.ts
```

On Node 22, import `hello` from your own module and call it. lamina's tests run this app in Node 22, 24 and 26 and check that it writes exactly the bytes of the Rust quick start.

- **Free documents** you're done with (`using doc = …`, or `doc.free()`), so a long-running server doesn't wait for the garbage collector to release WebAssembly memory.

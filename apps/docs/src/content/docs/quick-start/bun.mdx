Bun resolves the `node` export condition, as Node does, and reads each `.wasm` file from `@lamina/wasm`.

This is the Bun runner of the example suite, which CI runs with `cargo xtask pdf-runtimes bun`:

<Snippet file="packages/pdf/test/bun/examples.test.ts" />

`runSuite` calls `await init({ text: true })` once. Then each example, such as [`hello`](/quick-start/node/), builds its bytes synchronously.

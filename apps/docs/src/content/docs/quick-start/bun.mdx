Bun loads `@laminapdf/sdk` the way Node does: it reads the `.wasm` files from the `@laminapdf/wasm` package.

This app builds one A4 page that says "Hello, world!" and writes it to `hello.pdf` with `Bun.write`:

<Snippet file="packages/sdk/examples/quick-start/bun.ts" />

Save it as `hello.ts` and run it:

```sh
bun hello.ts
```

lamina's tests run this app in Bun and check that it writes exactly the bytes of the Rust quick start.

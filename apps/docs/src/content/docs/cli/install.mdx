Install the `laminapdf` tool on macOS, Linux or Windows. Homebrew and npm install and update it with one command; a direct download suits a machine with neither, such as a build server.

## Homebrew

On macOS and Linux, Homebrew installs it from Lamina PDF's own tap:

```sh
brew install laudebugs/tap/laminapdf
```

## npm

npm installs the same tool, with no Rust or WebAssembly involved:

```sh
npm install -g @laminapdf/cli@{{version}}
```

To run it once without installing it, use `npx @laminapdf/cli@{{version}} info report.pdf`. The package holds a small launcher, and npm installs the build for your system as one of its optional dependencies. No install script runs and nothing else is downloaded.

Every link above is for version {{version}}; the [release page](https://github.com/laudebugs/laminapdf/releases/tag/laminapdf-cli-v{{version}}) also has `sha256.sum`, every checksum in one file.

### Check the download

A checksum proves the archive arrived as the release built it. On macOS and Linux, run this in the folder holding both files. It prints `OK` beside the archive's name, and may also warn about a blank line in the checksum file, which you can ignore:

```sh
shasum -a 256 -c laminapdf-cli-aarch64-apple-darwin.tar.xz.sha256
```

On Windows, `Get-FileHash laminapdf-cli-x86_64-pc-windows-msvc.zip` in PowerShell prints the hash to compare with the one in the `.sha256` file.

### Allow it to run

The tool isn't signed yet. On macOS, a program downloaded with a browser is quarantined, and Gatekeeper refuses to open it. Remove the quarantine once, from the unpacked folder:

```sh
xattr -d com.apple.quarantine laminapdf
```

On Windows, SmartScreen may warn the first time you run it. Homebrew and npm installs avoid most of these warnings, and `curl` downloads aren't quarantined.

### What the archive holds

Besides the `laminapdf` program, each archive holds its licences (`LICENSE-MIT` and `LICENSE-APACHE`) and `THIRD_PARTY_NOTICES.md`, the licence of every library inside the program. It also has a manual page per command in `man/`, which `man ./man/laminapdf-info.1` reads in place, and shell completions in `completions/`. Homebrew and npm install neither, but the tool writes its completions itself.

## Shell completions

The tool writes the completion script for your shell, so Tab completes its commands and flags. For zsh, write it to a folder on your `fpath`:

```sh
laminapdf completions zsh > ~/.zfunc/_laminapdf
```

It also writes `bash`, `fish`, `powershell` and `elvish` scripts.

## Check that it works

`laminapdf --version` prints the version, and `laminapdf help` lists the commands:

```console
$ laminapdf --version
laminapdf {{version}}
```

## Try a change before it's released

To try a change that isn't released yet, build the tool from the repository with Cargo, the MCP server included:

```sh
cargo install --git https://github.com/laudebugs/laminapdf laminapdf-cli --features mcp
```

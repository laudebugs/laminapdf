Each example exists twice: in Rust (`crates/lamina/examples/`) and in TypeScript (`packages/sdk/examples/`). Both write the same bytes, the golden in `fixtures/golden/examples/`. CI checks that in Rust and in every JavaScript runtime: Node, Chromium, Firefox, WebKit, Deno, Bun and workerd. The source below is those files, and each PDF link is the golden itself.

Run them yourself with `cargo run -p lamina --example <name>` (written to `target/examples-out/`), or `cargo xtask examples` to compare all of them with the goldens.

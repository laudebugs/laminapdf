Each example exists twice, in Rust and in TypeScript, and both write exactly the same bytes. Every change to lamina is tested for that in Rust and in every JavaScript runtime: Node, Chromium, Firefox, WebKit, Deno, Bun and workerd. The source below is the tested code, and each PDF link is the file it writes.

To run one yourself from a checkout of lamina, use `cargo run -p lamina --example <name>`; it writes the PDF to `target/examples-out/`.

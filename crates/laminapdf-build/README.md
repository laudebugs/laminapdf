# laminapdf-build

Generating PDFs (todos [B5a](../../docs/todos/done/B5a-lamina-build-core.md), [B5b](../../docs/todos/done/B5b-builder-text-and-document-features.md), [B8a](../../docs/todos/done/B8a-structure-tree.md) and [B8b](../../docs/todos/done/B8b-conformance-profiles-and-verapdf.md); [ADR 0005](../../docs/decisions/0005-document-model.md) §6): a builder that writes Lamina PDF `Object`s straight into a document's overlay, with content streams from `pdf_writer::Content`, as the [krilla-fit spike](../../spikes/krilla-fit/README.md) recommended. A new document is a `laminapdf_ops::Document` over an empty base (`laminapdf_cos::Document::empty`), `Dirty` until it is saved (a full rewrite, `laminapdf-save`'s `NoBase`); adding pages to an open document is the same code and saves incrementally. Part of Lamina PDF's pure core: bytes in, bytes out, no clocks, no hash maps, byte-deterministic output. Spec: ISO 32000-2 §7.7 (pages), §8.4–8.6 (graphics state, paths, colour), §8.9 (images), §9.2–9.4 (text), §11.3.5 and §11.6 (blend modes, soft masks), §12.3–12.5 (destinations, outlines, page labels, link annotations), §14.3 (Info, XMP), §14.7–14.8 (structure tree, marked content, artifacts), §14.9 (`/Lang`, `/Alt`, `/ActualText`); background in [research 02](../../docs/research/pdf/02-imaging-model.md), [03](../../docs/research/pdf/03-text-and-fonts.md) and [04](../../docs/research/pdf/04-interactive-security.md).

- **`Builder`** (`Builder::new(BuildOptions)`: header version, a fixed `/ID[0]`, a minimal Info with `/Producer` and `/CreationDate` given by the caller, content compression, the `OpenOptions` the document carries) → `page(PageSize)` → `PageBuilder` (`rotate`, `user_unit`, `crop_box`, `bleed_box`, `trim_box`, `art_box`, `surface()`) → `PageBuilder::finish()` (returns the new page's `PageId`) → `Builder::finish()` (page tree, catalog, Info, trailer). The catalog and the page tree root are objects 1 and 2. `PageSize` has A0–A6, Letter, Legal, Tabloid and `landscape()`.
- **`Builder::on(&mut laminapdf_model::Document, &BuildOptions)`** (only compression applies) → `Appender`: pages appended to the root `/Pages` node's `/Kids` (direct or an indirect array) with `/Count` updated; existing objects and `PageId`s are untouched, new pages write `/Rotate` and `/CropBox` so nothing is inherited, and `IncrementalWriter` saves the result. These edits are not op-log transactions (there is no op for drawn content yet). Resources are deduplicated within one appender, not against objects already in the document, so the same image added through two `Builder::on` calls is embedded twice.
- **Coordinates** ([ADR 0027](../../docs/decisions/0027-coordinates-units-and-page-indexing.md)): every position and length is page space: `Pt`, `PointPt`, `RectPt` (from `laminapdf-model`, re-exported) in points from the top-left of the page as displayed (its CropBox after `/Rotate`), y down, `/UserUnit` applied. The `Surface` records drawing in page space and maps it to user space through the page's `PageFrame` when the page is finished, so the page's rotation, crop box and unit can be set in any order; `transform` matrices are conjugated into user space. Page boxes are given in the MediaBox's displayed page space.
- **`Surface`**: `save`/`restore` (balanced at the end of the page whatever the caller did), `transform(Matrix)`, `path(|p| …)` with `PathBuilder` (`move_to`, `line_to`, `cubic_to`, `quad_to` as the equivalent cubic, `close`, `rect` as `re` starting at its top-left, `ellipse` and `circle` as four cubics; a segment without a current point starts a subpath) returning a `PendingPath` that borrows the surface until it is painted with `stroke(&StrokeStyle { width, cap, join, miter_limit, dash })`, `fill(FillRule)`, `fill_stroke` or `clip(FillRule)` (`W n`), so nothing can come between a path and its painting operator; `fill_color`/`stroke_color`, `opacity(fill, stroke)` and `blend_mode(BlendMode)` as `ExtGState`s, `image(&Image, RectPt)`. Invalid drawing values (non-finite coordinates or matrices, negative widths, negative or all-zero dashes, miter limits below 1) are reported by `PageBuilder::finish` as `invalid-geometry`. Features newer than the document's version (`/UserUnit` 1.6, 16-bit images 1.5, transparency and soft masks 1.4) raise it through the catalog's `/Version`. Operators that would change nothing (a colour or line parameter already set in the current graphics state) are not repeated.
- **Colour**: `Color::{Gray, Rgb, Cmyk}` (clamped), `Color::hex("#rrggbb" | "#rgb")`, and `ICCBased` colour: `IccProfile::new(bytes)` checks the header (size, `acsp`, profile class, data colour space → `/N`: Gray 1, RGB 3, CMYK 4; Lab is refused, as it needs a `/Range`) and `Color::icc(&profile, &components)` checks the component count; the profile is written once per document with `/N` and the device `/Alternate`.
- **Images**: `Image::jpeg(bytes)` passes the bytes through as `DCTDecode` with size and components from the frame header (fill bytes and length-less markers handled; arithmetic, lossless, hierarchical and 12-bit JPEG refused); an Adobe CMYK JPEG gets `/Decode [1 0 1 0 1 0 1 0]`. `Image::png(bytes)` / `png_with(bytes, PngOptions { downconvert_16 })` decodes with the `png` crate (palettes and `tRNS` expanded, low bit depths to 8, 16-bit kept by default, interlacing removed, at most `MAX_DECODED_IMAGE_BYTES` = 256 MiB decoded); alpha becomes an `/SMask`, left out when every pixel is opaque. `Image::rgba(width, height, &bytes)` takes raw RGBA. Equal images (by SHA-256 of their samples and parameters) are one XObject per document.
- **Resources**: named per page in order of first use (`GS1`, `CS1`, `Im1`, …); `ExtGState`s, profiles and images are each written once per document.
- **Fonts and text** (B5b, through `laminapdf-text`): `Builder::font(laminapdf_text::Font)` / `font_with(font, EmbedPolicy)` / `standard_font(Standard14)` (also on `Appender`) return a `Font` handle; one `FontRegistry` per build, fonts subset and written when the build finishes. `Surface::text(str, &Font, size, at)`: **`at.y` is the baseline** (ADR 0027 §5), `at.x` the run's left edge; shaped with HarfRust, bidi-resolved and drawn in visual positions (runs in logical order through `Line::drawing_order`, so extractors read right-to-left lines in order), real space glyphs, `/ActualText` spans where `pdf_run` asks (raising the version to 1.5), a line feed starting a line 1.2 × size lower; returns a `TextRun` (`fill`, `render_mode` `Fill`/`Stroke`/`FillStroke`/`Invisible`, `features`, `language`, `direction` re-shape; `link(target, contents)` over its transformed bounding box; `width`, `bounds`, `lines`). `Surface::text_box(str, &Font, size, RectPt, &TextBoxOptions { align, line_height, overflow: Clip | Error, direction, language, features })` breaks greedily at UAX #14 opportunities (`break_lines`), first baseline the ascent below the box's top, and returns a `TextLayout` (`LineBox`es with range, content, rect and baseline; `overflow`: where undrawn text starts); `Overflow::Error` is `text-overflow` and draws nothing. Standard 14 fonts are measured with their AFM widths and laid out left to right by the builder (no shaping). Emitted as `BT`, `Tr` (only when it changes), `Tf`, `Tm` per run, `TJ` with `Ts` rises, `ET`.
- **Links** (§12.5.6.5): `Surface::link(RectPt, LinkTarget, contents)` (through the current transform) and `TextRun::link`: `/Subtype /Link`, `/Border [0 0 0]`, `/F 4`, `/Contents`, and `/A /URI` (non-ASCII percent-encoded) or `/Dest`. `LinkTarget::{Uri, Page { index, fit }, Named}`; `Fit::{Page, Width, Height, Xyz, Rect, Bounds}` in page space, mapped through the target page's frame. Annotation numbers are reserved when the page finishes and targets resolved when the build does, so a link can name a later page (`page-index-out-of-range`, `unknown-destination` otherwise; an appender resolves against every page of the document and doesn't check names).
- **Document features** (new documents): `Builder::destination(name, index, fit)` → `/Names /Dests` (one sorted leaf); `Builder::outline(entries)` with `OutlineEntry` (`new`, `heading`, children, `open`, colour, bold, italic) → `/Outlines` with `/First`/`/Last`/`/Prev`/`/Next`/`/Parent`/`/Count`, each item's `OutlineItemId` allocated at the call (pre-order); `Builder::page_labels([PageLabel])` → `/PageLabels` (`invalid-page-labels` unless the first starts at 0, starts increase, are pages, numbers from 1); `Builder::metadata(Metadata { title, author, subject, keywords, creator, producer, creation_date, mod_date })` → Info and an uncompressed `/Metadata` XMP packet from the same values (dates given, never read from a clock; `BuildOptions`' producer and date as fallbacks); `Builder::lang`; `Builder::viewer_preferences(ViewerPreferences { display_doc_title, page_mode, page_layout })`. Versions are raised as needed (`/Names` 1.2, labels 1.3, XMP, `/Lang`, outline styles and `DisplayDocTitle` 1.4).
- **Tagged PDF** (B8a, `src/tag/`): `BuildOptions::with_tagged(true)` (or any page using an element or artifact) makes the document tagged: `/MarkInfo << /Marked true >>` and a `/StructTreeRoot` whose one `Document` element holds each page's top-level elements in order. `Surface::tag(impl Into<Tag>, |s| …)` (the closure returns `Result`; the element ends either way), `TextRun::tag`, `Surface::figure(&Image, RectPt, alt)` (a `Figure` with `/Alt`) and `Surface::artifact(ArtifactKind::{Layout, Page, Pagination, Background}, |s| …)` (`/Artifact <</Type …>> BDC`; a background's `/BBox` is the crop box), with `begin_tag`/`begin_artifact`/`end_tag` for bindings. `Tag::new(TagKind)` (`Document`, `Part`, `Sect`, `H1`–`H6`, `P`, `L`/`LI`/`Lbl`/`LBody`, `Table`/`TR`/`TH`/`TD`, `Figure`, `Caption`, `Link`, `Span`, `Quote`, `Note`, `Code`) or `Tag::custom(name, role)` (a `RoleMap` entry), `with_alt`, `with_actual_text`, `with_expansion`, `with_lang`, `with_scope(TableScope)` (`/A << /O /Table /Scope … >>`). Each run of drawing inside an element is `/<Tag> <</MCID n>> BDC … EMC` (MCIDs from 0 per page; sequences close before `q`/`Q` and every element boundary, so they never nest); pages get `/StructParents`, link annotations `/StructParent` and an `OBJR` in a `Link` element (the innermost one, or one made for them), pages with links `/Tabs /S`; the `ParentTree` is one sorted `/Nums` leaf, with `/ParentTreeNextKey`. Inside an artifact, elements are part of the artifact. Elements are per page; appended pages are never tagged. `Builder::tagging_diagnostics()` lists, per finished page, content drawn and link annotations made outside every element (`TagDiagnostic::Untagged`; a clip alone doesn't count, an artifact's drawings do have structure, its links don't) and figures without `/Alt` or `/ActualText` (`MissingAlt`), for B8b's profiles; nothing while the document is untagged, everything from pages finished before it became tagged. A `Tag::custom` name that is a standard type (PDF 1.7 or 2.0) is written unmapped. `/Tabs /S` and `/E` raise the version to 1.5. Untagged documents are written exactly as before.
- **Conformance profiles** (B8b, `src/profile/`): `BuildOptions::with_profile(Profile::{PdfUa1, PdfA2b, PdfA2u, PdfA3b})` (PDF/UA-1 combines with one PDF/A profile; a second PDF/A profile replaces the first; `Profile::None` clears them). `Builder::finish` checks, before writing anything, the machine-checkable rules the builder could break and fails with the first one's coded error: PDF/UA-1's title, language, untagged content, figures without alternate text, skipped heading levels, table and list nesting, links outside a `Link` element or without `/Contents` (Matterhorn Protocol 1.1 conditions, listed in `profile/checks.rs`); every profile's embedded fonts (no standard 14) and PDF 1.x; PDF/A-2u's and PDF/UA-1's Unicode for every glyph; PDF/A's `DeviceCMYK` (the output intent is sRGB) and PDF/A-2's attachments. It then writes the XMP packet whatever `metadata` was given (`pdfaid:part`/`conformance`, `pdfuaid:part`, and a PDF/A extension schema for `pdfuaid` when the document is both), `/DisplayDocTitle true` under PDF/UA-1, and for PDF/A one `GTS_PDFA1` output intent whose `/DestOutputProfile` is the 480-byte CC0 sRGB v4 profile in `data/` (provenance in [`data/README.md`](data/README.md)). PDF/UA-1 makes the document tagged. Rules no program can check (the quality of alternate text, a sensible reading order) stay the caller's.
- **Attachments** (B8b, `src/attach.rs`): `Builder::attach(Attachment::new(name, bytes, mime).with_relationship(AfRelationship::…).with_description(…).with_mod_date(…))` → an `/EmbeddedFile` stream (Flate, `/Subtype` the MIME type, `/Params` with `/Size` and `/ModDate`, by default the creation date), a file specification with `/F`, `/UF`, `/EF`, `/Desc` and `/AFRelationship`, one sorted `/Names /EmbeddedFiles` leaf and the catalog's `/AF`; the same name again replaces the file; `/UF` raises the version to 1.7.
- **Errors** (`buildErrors` in `fixtures/codes.json`, pages in `docs/errors/`): `invalid-image`, `unsupported-image`, `image-too-large`, `image-data-length`, `invalid-icc-profile`, `color-components`, `invalid-color`, `invalid-geometry`, `text-overflow`, `page-index-out-of-range`, `unknown-destination`, `invalid-page-labels`; the profiles' codes, from `profile-version-conflict` on in `buildErrors`; and the text (`missing-glyph`, `unknown-font`, …) and COS errors.

Not here: PDF/A-1, PDF/A-4 and PDF/UA-2, a CMYK or caller-chosen output intent, `QuadPoints` for rotated links, font fallback within a run, editing Info/XMP of existing documents (E1), the `laminapdf` façade ([B5c](../../docs/todos/done/B5c-lamina-facade-and-examples.md)), table `/Headers` and spans, elements spanning pages, merging structure trees (E2), shadings, patterns and Form XObjects as API (later).

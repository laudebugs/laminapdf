# lamina-build

Generating PDFs (todos [B5a](../../docs/todos/done/B5a-lamina-build-core.md) and [B5b](../../docs/todos/done/B5b-builder-text-and-document-features.md); [ADR 0005](../../docs/decisions/0005-document-model.md) §6): a builder that writes lamina `Object`s straight into a document's overlay, with content streams from `pdf_writer::Content`, as the [krilla-fit spike](../../spikes/krilla-fit/README.md) recommended. A new document is a `lamina_ops::Document` over an empty base (`lamina_cos::Document::empty`), `Dirty` until it is saved (a full rewrite, `lamina-save`'s `NoBase`); adding pages to an open document is the same code and saves incrementally. Part of lamina's pure core: bytes in, bytes out, no clocks, no hash maps, byte-deterministic output. Spec: ISO 32000-2 §7.7 (pages), §8.4–8.6 (graphics state, paths, colour), §8.9 (images), §9.2–9.4 (text), §11.3.5 and §11.6 (blend modes, soft masks), §12.3–12.5 (destinations, outlines, page labels, link annotations), §14.3 (Info, XMP), §14.9.4 (`/ActualText`); background in [research 02](../../docs/research/pdf/02-imaging-model.md), [03](../../docs/research/pdf/03-text-and-fonts.md) and [04](../../docs/research/pdf/04-interactive-security.md).

- **`Builder`** (`Builder::new(BuildOptions)`: header version, a fixed `/ID[0]`, a minimal Info with `/Producer` and `/CreationDate` given by the caller, content compression, the `OpenOptions` the document carries) → `page(PageSize)` → `PageBuilder` (`rotate`, `user_unit`, `crop_box`, `bleed_box`, `trim_box`, `art_box`, `surface()`) → `PageBuilder::finish()` (returns the new page's `PageId`) → `Builder::finish()` (page tree, catalog, Info, trailer). The catalog and the page tree root are objects 1 and 2. `PageSize` has A0–A6, Letter, Legal, Tabloid and `landscape()`.
- **`Builder::on(&mut lamina_model::Document, &BuildOptions)`** (only compression applies) → `Appender`: pages appended to the root `/Pages` node's `/Kids` (direct or an indirect array) with `/Count` updated; existing objects and `PageId`s are untouched, new pages write `/Rotate` and `/CropBox` so nothing is inherited, and `IncrementalWriter` saves the result. These edits are not op-log transactions (there is no op for drawn content yet). Resources are deduplicated within one appender, not against objects already in the document, so the same image added through two `Builder::on` calls is embedded twice.
- **Coordinates** ([ADR 0027](../../docs/decisions/0027-coordinates-units-and-page-indexing.md)): every position and length is page space: `Pt`, `PointPt`, `RectPt` (from `lamina-model`, re-exported) in points from the top-left of the page as displayed (its CropBox after `/Rotate`), y down, `/UserUnit` applied. The `Surface` records drawing in page space and maps it to user space through the page's `PageFrame` when the page is finished, so the page's rotation, crop box and unit can be set in any order; `transform` matrices are conjugated into user space. Page boxes are given in the MediaBox's displayed page space.
- **`Surface`**: `save`/`restore` (balanced at the end of the page whatever the caller did), `transform(Matrix)`, `path(|p| …)` with `PathBuilder` (`move_to`, `line_to`, `cubic_to`, `quad_to` as the equivalent cubic, `close`, `rect` as `re` starting at its top-left, `ellipse` and `circle` as four cubics; a segment without a current point starts a subpath) returning a `PendingPath` that borrows the surface until it is painted with `stroke(&StrokeStyle { width, cap, join, miter_limit, dash })`, `fill(FillRule)`, `fill_stroke` or `clip(FillRule)` (`W n`), so nothing can come between a path and its painting operator; `fill_color`/`stroke_color`, `opacity(fill, stroke)` and `blend_mode(BlendMode)` as `ExtGState`s, `image(&Image, RectPt)`. Invalid drawing values (non-finite coordinates or matrices, negative widths, negative or all-zero dashes, miter limits below 1) are reported by `PageBuilder::finish` as `invalid-geometry`. Features newer than the document's version (`/UserUnit` 1.6, 16-bit images 1.5, transparency and soft masks 1.4) raise it through the catalog's `/Version`. Operators that would change nothing (a colour or line parameter already set in the current graphics state) are not repeated.
- **Colour**: `Color::{Gray, Rgb, Cmyk}` (clamped), `Color::hex("#rrggbb" | "#rgb")`, and `ICCBased` colour: `IccProfile::new(bytes)` checks the header (size, `acsp`, profile class, data colour space → `/N`: Gray 1, RGB 3, CMYK 4; Lab is refused, as it needs a `/Range`) and `Color::icc(&profile, &components)` checks the component count; the profile is written once per document with `/N` and the device `/Alternate`.
- **Images**: `Image::jpeg(bytes)` passes the bytes through as `DCTDecode` with size and components from the frame header (fill bytes and length-less markers handled; arithmetic, lossless, hierarchical and 12-bit JPEG refused); an Adobe CMYK JPEG gets `/Decode [1 0 1 0 1 0 1 0]`. `Image::png(bytes)` / `png_with(bytes, PngOptions { downconvert_16 })` decodes with the `png` crate (palettes and `tRNS` expanded, low bit depths to 8, 16-bit kept by default, interlacing removed, at most `MAX_DECODED_IMAGE_BYTES` = 256 MiB decoded); alpha becomes an `/SMask`, left out when every pixel is opaque. `Image::rgba(width, height, &bytes)` takes raw RGBA. Equal images (by SHA-256 of their samples and parameters) are one XObject per document.
- **Resources**: named per page in order of first use (`GS1`, `CS1`, `Im1`, …); `ExtGState`s, profiles and images are each written once per document.
- **Fonts and text** (B5b, through `lamina-text`): `Builder::font(lamina_text::Font)` / `font_with(font, EmbedPolicy)` / `standard_font(Standard14)` (also on `Appender`) return a `Font` handle; one `FontRegistry` per build, fonts subset and written when the build finishes. `Surface::text(str, &Font, size, at)`: **`at.y` is the baseline** (ADR 0027 §5), `at.x` the run's left edge; shaped with HarfRust, bidi-resolved and drawn in visual positions (runs in logical order through `Line::drawing_order`, so extractors read right-to-left lines in order), real space glyphs, `/ActualText` spans where `pdf_run` asks (raising the version to 1.5), a line feed starting a line 1.2 × size lower; returns a `TextRun` (`fill`, `render_mode` `Fill`/`Stroke`/`FillStroke`/`Invisible`, `features`, `language`, `direction` re-shape; `link(target, contents)` over its transformed bounding box; `width`, `bounds`, `lines`). `Surface::text_box(str, &Font, size, RectPt, &TextBoxOptions { align, line_height, overflow: Clip | Error, direction, language, features })` breaks greedily at UAX #14 opportunities (`break_lines`), first baseline the ascent below the box's top, and returns a `TextLayout` (`LineBox`es with range, content, rect and baseline; `overflow`: where undrawn text starts); `Overflow::Error` is `text-overflow` and draws nothing. Standard 14 fonts are measured with their AFM widths and laid out left to right by the builder (no shaping). Emitted as `BT`, `Tr` (only when it changes), `Tf`, `Tm` per run, `TJ` with `Ts` rises, `ET`.
- **Links** (§12.5.6.5): `Surface::link(RectPt, LinkTarget, contents)` (through the current transform) and `TextRun::link`: `/Subtype /Link`, `/Border [0 0 0]`, `/F 4`, `/Contents`, and `/A /URI` (non-ASCII percent-encoded) or `/Dest`. `LinkTarget::{Uri, Page { index, fit }, Named}`; `Fit::{Page, Width, Height, Xyz, Rect, Bounds}` in page space, mapped through the target page's frame. Annotation numbers are reserved when the page finishes and targets resolved when the build does, so a link can name a later page (`page-index-out-of-range`, `unknown-destination` otherwise; an appender resolves against every page of the document and doesn't check names).
- **Document features** (new documents): `Builder::destination(name, index, fit)` → `/Names /Dests` (one sorted leaf); `Builder::outline(entries)` with `OutlineEntry` (`new`, `heading`, children, `open`, colour, bold, italic) → `/Outlines` with `/First`/`/Last`/`/Prev`/`/Next`/`/Parent`/`/Count`, each item's `OutlineItemId` allocated at the call (pre-order); `Builder::page_labels([PageLabel])` → `/PageLabels` (`invalid-page-labels` unless the first starts at 0, starts increase, are pages, numbers from 1); `Builder::metadata(Metadata { title, author, subject, keywords, creator, producer, creation_date, mod_date })` → Info and an uncompressed `/Metadata` XMP packet from the same values (dates given, never read from a clock; `BuildOptions`' producer and date as fallbacks); `Builder::lang`; `Builder::viewer_preferences(ViewerPreferences { display_doc_title, page_mode, page_layout })`. Versions are raised as needed (`/Names` 1.2, labels 1.3, XMP, `/Lang`, outline styles and `DisplayDocTitle` 1.4).
- **Errors** (`buildErrors` in `fixtures/codes.json`, pages in `docs/errors/`): `invalid-image`, `unsupported-image`, `image-too-large`, `image-data-length`, `invalid-icc-profile`, `color-components`, `invalid-color`, `invalid-geometry`, `text-overflow`, `page-index-out-of-range`, `unknown-destination`, `invalid-page-labels`, and the text (`missing-glyph`, `unknown-font`, …) and COS errors.

Not here: the structure tree and `tag()` ([B8a](../../docs/todos/ready/B8a-structure-tree.md)), PDF/A XMP schemas ([B8b](../../docs/todos/ready/B8b-conformance-profiles-and-verapdf.md)), `QuadPoints` for rotated links, font fallback within a run, editing Info/XMP of existing documents (E1), the `lamina` façade ([B5c](../../docs/todos/ongoing/B5c-lamina-facade-and-examples.md)), tagging and conformance (B8), shadings, patterns and Form XObjects as API (later).

Tests (`tests/`, reading the shared [`fixtures/`](../../fixtures/README.md)): `goldens.rs` (the eight goldens byte for byte, twice the same, and read back without warnings by the reader, the model's frame and `lamina-content`), `vectors.rs` (page space through every `/Rotate` value against the reader's `PageFrame`, the current point after `re`, `/UserUnit`, transforms, balanced `q`/`Q`, opacity and ICC resources, version raising, refusals), `images.rs` (`/SMask`, JPEG bytes unchanged, Adobe CMYK, 16-bit, palettes, placement, dedup, limits), `append.rs` (`Builder::on` with `fixtures/corpus/hello.pdf`: incremental, IDs kept; nothing inherited from the tree root; compression option; `/Version` raised on a 1.3 base), `codes.rs` (`buildErrors` against `Error::CODES`), `content.rs` (the spike's content builder); B5b's `text.rs` (baseline on every rotation, the goldens' text through `lamina-content` with ToUnicode, standard 14 simple fonts, render modes, features, refusals, `/ActualText` versions, transformed link bounds), `textbox.rs` (no line wider than its box in five scripts, overflow clipped or refused, alignment, line height, RTL), `links.rs` (targets through the model, the sorted `/Dests` tree, refusals, appended pages linking to existing ones), `outline.rs` (the model's outline view, `/Count`, flags, IDs), `labels.rs`, `metadata.rs` (Info = XMP, `/Lang`, preferences, no ambient time) and `external.rs` (pypdf's, pdf.js's and pdftotext's text, the first two's links, outline, destinations, labels, Info and XMP from `fixtures/build/facts.json`, with `extraction-exceptions.json`). `tests/common/` holds the golden samples (`samples.rs`, `b5b.rs`; `legacy.rs` rebuilds the frozen `hello.pdf` and `imaging-demo.pdf` byte for byte with `lamina-save`'s `Writer` and the spike's content builder `content.rs`, which `lamina-save`'s tests include by `#[path]`), a `lamina-content` visitor, a ToUnicode-decoding text reader (`text.rs`) and a PNG writer. `examples/golden.rs` writes the goldens for `cargo xtask golden --update`; the full lane's round trip (qpdf, pdf.js, PDFium) includes `vectors.pdf`, `images.pdf` and B5b's four goldens, and pdf.js's operator counts for them are in `fixtures/corpus/pdfjs-operators.json`.

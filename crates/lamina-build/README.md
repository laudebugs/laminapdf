# lamina-build

Generating PDFs (todo [B5a](../../docs/todos/done/B5a-lamina-build-core.md); [ADR 0005](../../docs/decisions/0005-document-model.md) §6): a builder that writes lamina `Object`s straight into a document's overlay, with content streams from `pdf_writer::Content`, as the [krilla-fit spike](../../spikes/krilla-fit/README.md) recommended. A new document is a `lamina_ops::Document` over an empty base (`lamina_cos::Document::empty`), `Dirty` until it is saved (a full rewrite, `lamina-save`'s `NoBase`); adding pages to an open document is the same code and saves incrementally. Part of lamina's pure core: bytes in, bytes out, no clocks, no hash maps, byte-deterministic output. Spec: ISO 32000-2 §7.7 (pages), §8.4–8.6 (graphics state, paths, colour), §8.9 (images), §11.3.5 and §11.6 (blend modes, soft masks); background in [research 02](../../docs/research/pdf/02-imaging-model.md).

- **`Builder`** (`Builder::new(BuildOptions)`: header version, a fixed `/ID[0]`, a minimal Info with `/Producer` and `/CreationDate` given by the caller, content compression, the `OpenOptions` the document carries) → `page(PageSize)` → `PageBuilder` (`rotate`, `user_unit`, `crop_box`, `bleed_box`, `trim_box`, `art_box`, `surface()`) → `PageBuilder::finish()` (returns the new page's `PageId`) → `Builder::finish()` (page tree, catalog, Info, trailer). The catalog and the page tree root are objects 1 and 2. `PageSize` has A0–A6, Letter, Legal, Tabloid and `landscape()`.
- **`Builder::on(&mut lamina_model::Document)`** → `Appender`: pages appended to the root `/Pages` node's `/Kids` (direct or an indirect array) with `/Count` updated; existing objects and `PageId`s are untouched, new pages write `/Rotate` and `/CropBox` so nothing is inherited, and `IncrementalWriter` saves the result. These edits are not op-log transactions (there is no op for drawn content yet).
- **Coordinates** ([ADR 0027](../../docs/decisions/0027-coordinates-units-and-page-indexing.md)): every position and length is page space: `Pt`, `PointPt`, `RectPt` (from `lamina-model`, re-exported) in points from the top-left of the page as displayed (its CropBox after `/Rotate`), y down, `/UserUnit` applied. The `Surface` records drawing in page space and maps it to user space through the page's `PageFrame` when the page is finished, so the page's rotation, crop box and unit can be set in any order; `transform` matrices are conjugated into user space. Page boxes are given in the MediaBox's displayed page space.
- **`Surface`**: `save`/`restore` (balanced at the end of the page whatever the caller did), `transform(Matrix)`, `path(|p| …)` with `PathBuilder` (`move_to`, `line_to`, `cubic_to`, `quad_to` as the equivalent cubic, `close`, `rect` as `re`, `ellipse` and `circle` as four cubics), `stroke(&StrokeStyle { width, cap, join, miter_limit, dash })`, `fill(FillRule)`, `fill_stroke`, `clip(FillRule)` (`W n`), `fill_color`/`stroke_color`, `opacity(fill, stroke)` and `blend_mode(BlendMode)` as `ExtGState`s, `image(&Image, RectPt)`. Operators that would change nothing (a colour or line parameter already set in the current graphics state) are not repeated.
- **Colour**: `Color::{Gray, Rgb, Cmyk}` (clamped), `Color::hex("#rrggbb" | "#rgb")`, and `ICCBased` colour: `IccProfile::new(bytes)` checks the header (size, `acsp`, profile class, data colour space → `/N`: Gray 1, RGB and Lab 3, CMYK 4) and `Color::icc(&profile, &components)` checks the component count; the profile is written once per document with `/N` and the device `/Alternate`.
- **Images**: `Image::jpeg(bytes)` passes the bytes through as `DCTDecode` with size and components from the frame header (fill bytes and length-less markers handled; arithmetic, lossless, hierarchical and 12-bit JPEG refused); an Adobe CMYK JPEG gets `/Decode [1 0 1 0 1 0 1 0]`. `Image::png(bytes)` / `png_with(bytes, PngOptions { downconvert_16 })` decodes with the `png` crate (palettes and `tRNS` expanded, low bit depths to 8, 16-bit kept by default, interlacing removed, at most `MAX_DECODED_IMAGE_BYTES` = 256 MiB decoded); alpha becomes an `/SMask`, left out when every pixel is opaque. `Image::rgba(width, height, &bytes)` takes raw RGBA. Equal images (by SHA-256 of their samples and parameters) are one XObject per document.
- **Resources**: named per page in order of first use (`GS1`, `CS1`, `Im1`, …); `ExtGState`s, profiles and images are each written once per document.
- **Errors** (`buildErrors` in `fixtures/codes.json`, pages in `docs/errors/`): `invalid-image`, `unsupported-image`, `image-too-large`, `image-data-length`, `invalid-icc-profile`, `color-components`, `invalid-color`, `invalid-geometry`, and the COS errors.

Not here: text, links, outlines, destinations, page labels, metadata/XMP and viewer preferences ([B5b](../../docs/todos/ready/B5b-builder-text-and-document-features.md); `draw_text`'s `y` will be the baseline, ADR 0027 §5), the `lamina` façade ([B5c](../../docs/todos/ready/B5c-lamina-facade-and-examples.md)), tagging and conformance (B8), shadings, patterns and Form XObjects as API (later).

Tests (`tests/`, reading the shared [`fixtures/`](../../fixtures/README.md)): `goldens.rs` (the four goldens byte for byte, twice the same, and read back without warnings by the reader, the model's frame and `lamina-content`), `vectors.rs` (page space through every `/Rotate` value against the reader's `PageFrame`, `/UserUnit`, transforms, balanced `q`/`Q`, opacity and ICC resources, refusals), `images.rs` (`/SMask`, JPEG bytes unchanged, Adobe CMYK, 16-bit, palettes, placement, dedup, limits), `append.rs` (`Builder::on` with `fixtures/corpus/hello.pdf`: incremental, IDs kept; nothing inherited from the tree root), `content.rs` (the spike's content builder). `tests/common/` holds the golden samples (`samples.rs`; `legacy.rs` rebuilds the frozen `hello.pdf` and `imaging-demo.pdf` byte for byte with `lamina-save`'s `Writer` and the spike's content builder `content.rs`, which `lamina-save`'s tests include by `#[path]`), a `lamina-content` visitor and a PNG writer. `examples/golden.rs` writes the goldens for `cargo xtask golden --update`; the full lane's round trip (qpdf, pdf.js, PDFium) includes `vectors.pdf` and `images.pdf`, and pdf.js's operator counts for them are in `fixtures/corpus/pdfjs-operators.json`.

```sh
cargo test -p lamina-build
cargo xtask golden --update        # after a sample changes; review `git diff fixtures/golden`
python3 tools/fixtures/images.py   # rewrites fixtures/images/ (macOS sips for the JPEGs)
```

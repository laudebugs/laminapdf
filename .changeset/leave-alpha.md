`0.2.0` is the first release that isn't an alpha. A plain `npm install @laminapdf/sdk` or `cargo add laminapdf` now installs it, and from here on releases follow SemVer as the [stability policy](https://docs.laminapdf.com/reference/stability/) says: a breaking change raises the minor version (`0.2` to `0.3`), so an upgrade within `0.2.x` needs no change to your code. The `alpha` npm tag stays on `0.2.0-alpha.6`.

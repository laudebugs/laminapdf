# Fonts, text and extraction

The Rust APIs of `laminapdf-text` and `laminapdf-extract`.

Fonts API (ADR 0005 §6; `laminapdf-text`, B4a): `Font::from_bytes(bytes)` / `Font::from_collection(bytes, index)` (skrifa), `font.instance(&[(OpenTypeTag::WEIGHT, 700.0)])` for variable fonts, `FontInfo`; a per-document `FontRegistry`: `add(font, EmbedPolicy)` (`fsType` restricted/bitmap-only → `font-not-embeddable` unless `EmbedPolicy::Override`; "no subsetting" → embedded whole, byte for byte), `reference(key, &doc)` reserves the Type 0 object in the overlay at first use, `encode(key, text)` (one glyph per char via the cmap; `missing-glyph`, never a silent `.notdef`) or `use_glyph(key, gid, text)` (shaped glyphs), and `finish_fonts(&mut CosMut)` subsets with `subsetter` and writes Type 0 / Identity-H, `CIDFontType2` (`/FontFile2`, `/CIDToGIDMap /Identity`, or a stream: B4d gives each (glyph, text) its own CID, a textless glyph a format-character CID mapped to `<>`) or `CIDFontType0` (one CID per glyph: a second text is `tounicode-conflict`) (`/FontFile3 /CIDFontType0C`), compressed `/W` and a ToUnicode CMap (≤ 100 entries per block). Subset tags hash the font bytes and the glyphs, so output is byte-deterministic. Standard 14 (B4c): `Font::standard(Standard14::Helvetica)` needs no bytes (metrics from Adobe's AFM files, generated into `src/std14/generated/` by `cargo run -p std14-gen`, never by hand); the registry writes it as a non-embedded `/Type1` simple font (one byte per character, `/WinAnsiEncoding` plus `/Differences` for other Latin glyphs, `encoding-full` past 37 of them; Symbol/ZapfDingbats built-in), `/Widths`, a descriptor, a one-byte ToUnicode CMap; `use_glyph` returns a `GlyphCode` (`Cid`/`Byte`, `push_to`), `usage` a `FontUsage`; `Font::requires_embedding()` is `false` only for these; shaping and layout set them unshaped, a glyph per character with its AFM width (T4d), and `pdf_run` refuses them (`font-not-shapable`). `Encoding` (code ↔ glyph name) and `glyph_name_to_unicode` (the AGL) are shared with extraction; the crate's modules are private and every item is re-exported at its root (Q2s). Its codes are `textErrors`/`textWarnings` in `fixtures/codes.json`; text goldens `fixtures/golden/text-*.pdf` have pypdf/pdf.js/pdftotext/qpdf facts in `fixtures/text/extracted.json` (`tools/fixtures/text_facts.py`); font fixtures come from `tools/fixtures/fonts.py`. Text layout (B4b): `Shaper` with `HarfRust` (`shape(&font, text, &ShapeOptions)`, `Feature` from `"liga=0"`; `ShapedRun` glyphs with UTF-8 byte clusters in font units, matching `hb-shape` on `fixtures/shaping/`, written by `tools/shaping-goldens/goldens.py`), `BidiParagraph` (UAX #9: `unicode-bidi` on ICU4X data, `visual_runs(line)`), `line_breaks` (UAX #14, `icu_segmenter`'s Unicode 17 rules, no dictionary scripts) and `grapheme_boundaries`, `itemize`, `break_lines(&HarfRust, &fonts, text, &LayoutOptions)` (greedy, measured by shaping, aligned, visual order; draw runs in `Line::drawing_order()`, logical, for extraction), `break_spans(&HarfRust, &fonts, text, &[StyledSpan], &LayoutOptions)` (T4g, `src/layout/`: spans covering the text once, in order, else `invalid-spans`, each with its own font list, size, rise, language and features defaulting to the options; breaks only at UAX #14 opportunities; equal styles shaped as one run; `LineRun::{spans, size, rise}`, `Line::{ascent, descent}` from the tallest run; `break_lines` is one span), `pdf_line_run(&line_run, …)` (`pdf_run` with the run's rise added to its `Ts`), and `pdf_run(&run, text, &mut registry, key)` (`TJ` arrays, `Ts` rises, ToUnicode entries, `/ActualText` pieces, now only for CFF fonts and default-ignorables). UAX conformance subsets are in `fixtures/unicode/` (Unicode-3.0); extraction facts for pypdf, pdf.js and pdftotext (poppler pinned in `doctor.rs`), with the known extractor bugs (upstream links) in `fixtures/text/extraction-exceptions.json`. Extraction (B9b, B9d): `TextExtractor::new().page(&model_doc, &page)` → `PageText` (`glyphs`: text, code, user-space origin and advance, a `Quad` in ADR 0027 page space from the font's ascent/descent, size, MCID, `ActualText` span, `invisible` for `Tr` 3/7; `runs`: `PageTextRun`s of one font, size, direction, MCID, span, visibility, artifact marking, clip box (`clip`) and colour (`color`) on one baseline, text in logical order (`ActualText`, else right-to-left runs ordered by glyph position and UAX #9); `lines()` trimmed; `visible()`; `frame`; `unmapped`), fonts parsed once per extractor; Unicode by ToUnicode, glyph names (AGL), UTF-16 predefined CMaps, the embedded font's `cmap`, else U+FFFD; problems are `laminapdf_cos::Warning`s `font-invalid`, `cmap-invalid`, `unmapped-glyph`. Encrypted text copies in `fixtures/text/encrypted/` (`tools/fixtures/text_encrypted.py`, qpdf).

Extraction for retrieval (ADR 0030; `laminapdf-extract`, L3a): `extract(&model_doc, &ExtractOptions, &CancelToken)` → `Extraction` (`source`: `ExtractedSource`, `pages`: `ExtractedPage` with ADR 0027's `Coordinates`, `blocks`, `dropped`), or `extract_job(&doc, &options)` → `ExtractJob::step(&doc, Budget)` (one page per unit; `Budget`, `Step`, `Phase` live in `laminapdf-syntax` beside `CancelToken`, the façade re-exports them) and `cancel_token()`; errors `ExtractError` (`cancelled`, `job-finished`, `page-index-out-of-range`, or the document's). Per page: `laminapdf-text`'s runs flagged (`Flags`: `invisible`, `off-page`, `tiny`, `clipped`, `low-contrast`, `covered`; flagged runs become `Dropped` entries with a character count, their text only with `DropOptions::keep_spans`), runs on one baseline joined into lines and split at gutters (`lines.rs`), lines at a line's pitch into blocks (`blocks.rs`), blocks ordered by XY-Cut++ (`xycut.rs`: masked cross-column blocks split bands, columns before rows except in grids of one-line blocks, right to left on right-to-left pages) or by content order (`ReadingOrder::ContentStream`); de-hyphenation and ligatures in `text_fix.rs`; soft limits `ExtractLimits` (`extract-limit-blocks`), `extract-reading-order-ambiguous` for mixed writing modes; column-order checks on layout order (T3b: `narrow-gutter` from gaps of 0.6–1 font size kept in ≥ 3 aligned lines, and half the lines, of a block (`Line::near_gutters`), `columns-revisited` within a band (a pair side by side at one height, then both columns again below it at about their widths), `near-grid` from a second, row-first cut of a mostly one-line group, ≤ 8 per page) raise `extract-column-order-uncertain` with a `reason` and give the blocks covered confidence 0.5. Block IDs `p<index>-b<n>`; serde (feature `serde`) gives the JSON names. Tables (L3b, `tables/`): `paint/`'s `Collector` gathers the page's rules (`tables/edges.rs`'s `Edges`) from `laminapdf-content` path events in the text's own pass (`laminapdf_text::TextExtractor::page_with` forwards them; stroked segments and rectangles, closed by `s`/`b`, and thin filled shapes), `lattice.rs` snaps (3 pt) and joins them, groups crossing rules, and builds each group's grid with merged cells from missing inner rules (non-rectangular merges: unmerged cells and `extract-table-ambiguous`; an empty grid, a lone box or a one-row strip is no table), `stream.rs` (`TableMode::LatticeAndStream`, off by default) takes ≥ 3 lines that split into the same ≥ 2 columns; cells take the paragraph pieces by centre (binary search on the grid; each piece in one cell or the flow), a bold or shaded first row is a header; `BlockKind::Table { rows, cols, detector }` with `Block::cells`, the tables' text out of the paragraph flow, tables ordered with the other blocks; `ExtractLimits::max_table_cells` (`extract-table-limit`); `tables/across.rs` (T3c, last in `finish`) links a table's parts over a page break (`Block::continues`, `continued_by`; JSON `continues`, `continuedBy`), which Markdown, `to_text` and chunks write as one table. Output (`output/`): `Extraction::to_markdown(&MarkdownOptions)` (pipe tables, HTML for spans, optional page markers), `to_text`, `chunks(&markdown, &ChunkOptions)` (whole blocks up to `max_tokens`, `overlap`, `SplitOn::{Headings, Blocks, Pages}`; `Chunk` with `blockIds`, `headingPath`, `pages`, `regions`, `textRange`, `tokensApprox` = chars / 4) → `Rendered { text, ranges }` (`TextRange` in Unicode code points), and with `serde` `to_json(&extraction, &markdown, &JsonOptions)` (ADR 0030 §1's keys in order, blocks with `textRange`) and `chunks_jsonl`; feature `schema` (schemars) gives `json_schema()`, committed as `schemas/extract.schema.json` and checked by `tests/output.rs` (`UPDATE_GOLDEN=1` rewrites it and `fixtures/extract/markdown/`). Across pages, once all are read (L3d, `job.rs`'s `finish`): `furniture.rs` moves running headers and footers (top or bottom 10%, the same text digits aside on ≥ 3 pages at a similar height) and page numbers to `dropped`, as `page.rs` does with `Artifact`-marked runs (`laminapdf_text::PageTextRun::artifact`), unless `DropOptions::furniture` is off; `headings.rs` (the body size by characters; larger or bold-at-body short blocks, up to six levels) and `lists.rs` (bullets and counters with a hanging indent, depth from the indent; `BlockKind::ListItem` text without its marker, `to_text` writes it back) give kinds; block IDs are renumbered. Structure tree and hidden-text flags (L3g): `tagged.rs` reads the tree once per extraction (`ReadingOrder::Auto` on a tagged file, or `ReadingOrder::Tagged`) into `(page, MCID)` → block (its first non-grouping block-type element; `RoleMap` applied; LI with `Lbl` marker and `L` depth, Table cells from TR/TH/TD with `/A` spans), and each page uses it when it covers ≥ 80% of the visible text and jumps back across columns on ≤ 10% of its moves (else `extract-struct-tree-ignored` and the layout; text outside the tree follows in layout order with `extract-untagged-content`); tree blocks carry `structPath`, `structRef`, confidence 1 and `TableDetector::Tagged`, and the layout's heading and list rules leave them alone. `clipped`: `laminapdf-content`'s `GraphicsState::clip_box` (W/W* paths and Form `/BBox`, as boxes) reaches `PageTextRun::clip`; `low-contrast`: `PageTextRun::color` (`CurrentColor::approx_rgb`) near white with no backdrop (`visibility::Backdrops`: non-white fills, images, shadings, collected with the table rules in one pass). `covered` (T2a): `paint/` records opaque covers (filled rectangles and subpaths that fill exactly their box, never a pattern; unmasked upright images unless the images together fill 90% of the page; cut to the clip and page; alpha 1, no soft mask, `Normal` or near-black `Multiply`/`Darken`; nothing in optional content or a translucent group) numbered by paint (`laminapdf_text::Glyph::paints_before`), and `paint/annots.rs` the opaque parts of shown annotations' normal appearances, after the page; `segments.rs` cuts covered stretches (a glyph's centre and half its box) out of runs into `dropped`, and `lines.rs` doesn't split a line where a covered box fills the gap. Model plug-ins (L3c, `plugins.rs`, `regions.rs`; ADR 0030 §6 amended): `LayoutModel::detect(&PageRaster, &CancelToken)` → `LayoutRegion { label: RegionLabel, bbox, score }`, `OcrEngine::recognise(&PageRaster, langs, &CancelToken)` → `OcrWord`s, both with `info()` → `ModelInfo` (name, version, sha256, licence); `PageRaster` is straight RGBA with its page box (`to_page` maps pixels), drawn by the caller's `PageRenderer`; `ExtractOptions::with_models(Models { layout, ocr: Option<ModelSlot<…>>, renderer, dpi (0 = 150), langs })`, `ModelSlot::Plugin(Arc<…>)` (run inside a step when a renderer is set) or `ModelSlot::Host(ModelInfo)`: the job reads a page, then `ExtractJob::request()` → `ModelRequest::{Layout, Ocr} { page, dpi, … }` (steps report `Phase::Model` and do nothing while it is open) until `provide(ModelResult)`; `extract()` in one call refuses host-only models (`model-needs-host`), a wrong result is `model-result-unexpected` (`extractErrors` in `codes.json`). Regions cut runs where glyphs cross a region's edge, build lines and blocks per region, order regions with XY-Cut++ and a region's blocks top to bottom, map labels to kinds (title → heading 1, section header → 2, list item, caption, footnote), take the region's score as confidence, drop page header/footer regions as `running-header`/`running-footer`, and run the stream table detector in a table region with no ruled table; OCR reads pages with no visible text (`has_visible_text`; a `Tr 3` layer doesn't count), its spans carry `ocr` confidence and its blocks their mean. `Extraction::models` feeds `generator.models`, `generator.mode` `rules+models`. Tests: `tests/plugins.rs` (fakes). Text layer (T3a): `marks.rs` (`Marks`, the page's one painting visitor: table rules, backdrops, image boxes clipped to the page and painted paths) and `text_layer.rs` (`measure`/`classify`) give every `ExtractedPage` a `TextLayer` (`status`: `TextLayerStatus::{Empty, OcrLayer, NeedsOcr, Mixed, Native}`, the first that applies; `chars`, `invisibleChars`, `unmappedShare`, `images`, `imageShare` on a 32 × 32 grid, `paths`) under `ExtractOptions::text_layer` (`TextLayerThresholds`, shares in thousandths); `needs-ocr` and `ocr-layer` pages raise `extract-needs-ocr` (data `status`). WASM, TypeScript and the benchmark L3e. Tests: `tests/reading_order.rs` (every file of `fixtures/reading-order/` in order by layout, but the 6 hard ones, which are warned), `tests/extract.rs` (built files), `tests/tables.rs`, `tests/output.rs`, `tests/regressions.rs` (the `extract` fuzz target's entry over the corpus). Reader mode (U4b, `reflow/`): `reflow(&doc, &CancelToken)` → `Reflow { available, reason, lang, blocks, checks }` over `ReadingOrder::Auto`'s blocks: `ReflowBlock`s in the tree's order (`ReflowKind`: heading, paragraph, list item, quote (a `BlockQuote`'s paragraphs), caption, note, and `Figure`/`Formula`/`Table` as crops with `/Alt`, boxed by what their marked content paints (`Marks`' per-MCID boxes, `job.rs`'s `PageFeed`) and the text they take in); `ReflowRefusal` `untagged`, `empty`, `generic` (over half the content in no block-level element), `coverage`/`order` (the per-page checks ignore the tree on over a quarter of its tagged pages), `order` (Kendall's τ against XY-Cut++ below 0.5, `reflow/order.rs`); `tests/reflow.rs` over `fixtures/reflow/`. A refused tree, or no tree, doesn't end reader mode (U4c, `reflow/approximate.rs`): `Reflow::source` is `ReflowSource::Approximate` and `reason` says why the tree wasn't used; the blocks are `ReadingOrder::Layout`'s, tables as crops that keep their text, images (those that overlap or touch joined first) at least 36 pt a side and under 85% of the page as figures placed before the first text below them in their column, text inside a figure (a chart's labels) kept in it, a short "Figure"/"Fig."/"Table" paragraph beside a crop its `Caption`; a page whose `TextLayerStatus` is `NeedsOcr` or `OcrLayer`, or with no text under a page-covering image, is a `ReflowKind::PageImage { why: Scanned }`, and one whose text's confidence by characters is under 0.65 (T3b's doubted blocks score 0.5) `PageImageReason::Uncertain`, with the page's text kept (on a scan, its OCR layer's); `ReflowRefusal::Nothing` only when no page has anything; `PageFeed::images` carries the page's image boxes; `tests/approximate.rs`, and `crates/laminapdf/tests/reading_order.rs` scores the approximate view over U2b's corpus against `approximate.mean` in `threshold.json` (a ratchet), caps its page images at `approximate.pageImages` (a ratchet that only goes down) and fails where it trails copy as paragraph.

# Reading, content, editing and saving

The Rust APIs of `laminapdf-cos`, `laminapdf-model`, `laminapdf-content`, `laminapdf-ops` and `laminapdf-save`.

Reading API (ADR 0003, 0005): `Document::open(source, OpenOptions)` takes an owned or shared `ByteSource` (`Vec<u8>`, `Arc<[u8]>`, `&'static [u8]`, `Arc<dyn ByteSource>`; in-memory ones are parsed in place, others are read in 64 KiB windows bounded by `Limits::max_read_window`, and a source answering `Pending` makes open or any lazy call fail with `Error::DataPending { ranges }` listing the ranges it needs next: windows, stream data or xref-entry probes; the edge crate `laminapdf-source` has `SparseSource`, filled with `supply(offset, bytes)`, and `retry`/`open_with`, which fetch those ranges and call again, plus `FileSource` and `MmapSource`); `OpenOptions` holds `Limits` (hard limits fail with `Error::LimitExceeded`, soft ones drop with a warning), strict mode (`Error::Strict`) and the password: the standard security handler (R2–R6, ISO 32000 §7.6) decrypts strings and streams on load, tries it as user then owner password (owner first for R5/R6), and fails with `password-required` or `wrong-password`; `Document::encryption()` and `permissions()` describe the result. Warning and error codes are listed once in `fixtures/codes.json` (v2: `code`, `kind`, `summary`, `hint`, `since` per code; ADR 0026; its schema is `fixtures/codes.schema.json`), from which `cargo xtask gen codes` generates every surface's tables (never edit them by hand; a new code is one entry, one `docs/errors/<code>.md` page, its `code()`/`kind()` arms and a regeneration), and which `crates/laminapdf-cos/tests/codes.rs` checks against the Rust enums and the `docs/errors/<code>.md` pages; every error and `Warning` has `code()`, `kind()` (one of nine `ErrorKind`s, an exhaustive match per type that each crate's unit tests check against the file) and `location()` (positions are tagged: `Position::{FileOffset, Object, InStream}`), and no `Display` formats text read from the input. Typed views live in `laminapdf-model`: its `Document` wraps the COS one (and derefs to it) with the ID allocator; `doc.pages()`, `doc.outline()`, `doc.info()`, `doc.page_labels()`, `doc.name_tree(key)`, `doc.initial_view()` (E3d, `src/initial_view.rs`: the open destination or another action's kind as `OpenAction`, `PageMode`, `PageLayout` (moved here from `laminapdf-build`, which re-exports them), `WindowPreferences`; `open_action_kind()` reads only the catalog's entry), `doc.threads()` (`src/threads.rs`: `Thread`s of `Bead`s, `/N` followed to the circle's end), `doc.disclosure()` (T2c, `src/disclosure/`: one scan of every object for the XMP packet, object-level metadata, `/PieceInfo`, `/Thumb`, embedded files and what holds them, every action a trigger fires through `/Next` with JavaScript sizes, annotations with author and comment, terminal form fields with full names and values, layers off by default and unreferenced objects; `Disclosure::redactions()`), `Info::keys()`, `doc.xmp()` (`laminapdf_model::xmp`, E1b: `PacketState::{Absent, Parsed(Packet), Malformed { bytes, error }}`, a malformed packet raising `xmp-invalid` and reading as absent; `Packet::parse` reads the `xpacket` wrapper, `x:xmpmeta`, several `rdf:Description`s, attribute and element forms, `parseType="Resource"`, `rdf:Alt`/`Seq`/`Bag` with `xml:lang`, namespaces by URI, UTF-8 or UTF-16, and refuses a DTD and any entity but XML's five; typed getters and setters for the fields of `MAPPINGS` (title, authors, subject, keywords, producer, creator tool, the three dates, document and instance IDs) and read-only `pdfa_part`/`pdfa_conformance`/`pdfua_part`; `Packet::write` gives the parsed bytes back when nothing changed, else replaces only the changed properties' bytes, keeps everything else, and pads back to the old length (2 KB of fresh padding when it doesn't fit), rewriting canonically only for a UTF-16 or read-only (`end="r"`) packet (`Written::canonical`); `Packet::new_minimal`; `escape`, `is_xml_char` and `PdfDate::to_iso8601` are the builder's too, and its packet matches `property_element` row by row; dates through `PdfDate::to_iso8601`/`from_iso8601`, and `to_pdf_string` for the ISO 32000-1 form without the trailing apostrophe); views raise warnings on the document via `laminapdf_cos::Document::report`. `LaminaPdfId`s are `p12.0` (kind + object) or path IDs such as `p5.0/Kids/3` for direct dictionaries (ADR 0005 §5).

Content API (ADR 0023): `laminapdf_content::ContentIter::new(&bytes)` tokenizes decoded content into `Op`s (Annex A `Operator` + operands; inline images whole) and `Issue`s; `interpret_page(&doc, &page, &mut visitor)` (or `interpret_content(&doc, &bytes, resources, &mut visitor)`) runs it with graphics/text state, resources, Form XObjects (depth `max_xobject_depth`, cycles by object identity) and marked content, calling `Visitor` methods (`show_text` returns the `TextAdvance` of the glyphs; glyph decoding is `laminapdf-text`'s). Content repairs are `laminapdf_cos::Warning`s (`content-*`, `inline-image-unterminated`, `xobject-cycle`) recorded on the document; `max_content_operators` counts every operator of one call, forms each time they are drawn. `GraphicsState` also tracks `blend_mode` (`laminapdf_model::BlendMode`) and `soft_mask` (whether `/SMask` is set; T2a); `Paint::draws` says whether a path paint draws. Append API (E2e, `src/write/`): `PageContentWriter::new(doc.edit(), &page)` writes one page through a `CosMut` (so a transaction or `rollback_to` undoes it): `wrap_existing()` → `Wrapped::{Already, Now { closing, neutralised, ended_text, ended_marked }}` adds a `q` stream before the content and a `Q` × (1 + depth) stream after it (`EMC`s and `ET` first for what the content leaves open; `limit-exceeded` past `max_nesting_depth` or `max_decoded_total`), turning each `Q` at depth 0 into `q Q` in a new copy of its stream (the only change to existing content), refusing content that ends inside a string, array, dictionary or inline image (`invalid-structure`) and leaving an already wrapped page alone (detected by structure); `prepend` (inside the wrap on a wrapped page)/`append` add Flate streams (refusing unbalanced content or content ending inside a token); `add_xobject`/`add_extgstate`/`add_font` pick an `Fm`/`Gs`/`Ft` name neither the resources nor the content uses, in the page's own copy of its resources; `scan_balance(&[streams], &limits)` → `Balance { depth, unmatched: Vec<StreamOffset>, max_depth, in_text, marked, wrapped }`. Fixtures `fixtures/content/append/` (`tools/fixtures/content_append.py`); render diffs in `laminapdf-render-pdfium`'s `tests/append.rs` (hayro leaves out the stray-`Q` fixtures: it restores the page's initial state on such a `Q`). Editing existing objects (E7d, ADR 0022): `ContentOps` (E7c's IR, `src/edit/`) gains `transform`, `crop`, `delete`, `replace_image`, `reorder(Placement)`, `resource_names` and `edit_refusal` (`edits.rs`: an edit wraps the object in `q cm … Q` and writes the state it set again after it; state set inside a `q … Q` an earlier edit opened stays there; refusals `clipping-path` for an object that clips what follows, `state-not-portable` for a reorder into another clip, transparency or `ExtGState` font); `PageContentWriter::write_parts` (each touched `/Contents` part a new Flate stream, copy on write), `add_image`, `remove_resources`. `laminapdf-ops`' `EditContent { page, edits: Vec<ContentEdit> }` (`src/content/`, class `Content`; `ContentEdit::{Transform, Delete, ReplaceImage { blob }, Crop, Reorder { to: StackPosition }}`, objects as `ObjectRef { ordinal, hash }`, `{ "ordinal": 0, "hash": "16 hex" }` on the wire, every name resolved before the first edit) prunes resources no operator names any more; image bytes from `Document::add_blob` (`unknown-blob`) through an injected `ImageXObjects` writer (`with_images`; `laminapdf_build::ImageXObjectWriter`, which the façade sets; `images-unavailable` without one). Façade `content_objects(index)` → `PageObject { object, kind, bounds, read_only }`, `hit_test`, `hit_test_rect`, `add_blob`; WASM `contentObjects`, `hitTest`, `hitTestRect`, `addBlob`; SDK `doc.content.objects`/`hitTest`/`edit`, `doc.addBlob`. Tests: `laminapdf-ops`' `tests/content.rs`, `laminapdf-save`'s `tests/content.rs` (planner verdicts) and the round-trip suite's `editContent` cases, `laminapdf-render`'s `tests/content_edits.rs` (hayro before and after: only the edited boxes change). Editing text (E7e, ADR 0022 §5–6): `laminapdf-text`'s `Glyph::show` (the show operator's count, which the recorder's `ContentOps::show_owners` matches to objects), `PageText::text_lines()` → `TextLine { text, runs, glyphs, bounds }` (which `lines()` is built on) and `TextExtractor::font_encoder(&doc, font, used)` → `FontEncoder` (`encode(text)` longest match first, else the character; `glyph(code)`; `refusal()`: `type3-font`, `vertical-text`, `no-unicode-map`; a subset's or composite font's codes only those the page uses); `ContentOps::rewrite_text(id, glyphs, range, new)` (`src/edit/text.rs`: `ShownGlyph`s, `ShownGlyph::gap` a `TJ` number; the show operators rewritten, `TJ` numbers in the range dropped, the line's next `Td`/`TD` takes the width difference and the next line move takes it back, before `T*`/`'`/`"` a `Td`). `laminapdf-ops`' `EditText { page, run: TextRunRef { object, start, end }, text }` (`src/content/text.rs`, class `Content`, empty text deletes; `missing-glyph` through `Error::Text`) and `text_runs(doc, page)` → `ContentTextRun { run, text, bounds, font_name, font_size, line, read_only }` (an extraction run split at each show operator, so an edit never spans a move; `text` with a space at word-sized gaps, written back as a 333 gap when the font has no space; forms' text left out; `actual-text`, `right-to-left`, `rotated-run`, `glyphs-out-of-order` added to the font's and object's reasons; codes past `/Widths` never offered); façade `text_runs(index)` (`content-edit` now implies `extract`), WASM `textRuns`, SDK `doc.content.textRuns`/`editText`; the `edit_text` example; tests `laminapdf-ops`' `tests/edit_text.rs`, the round-trip suite's `editText` case and `text_edits_round_trip_and_read_back_as_typed`. Editable IR (E7c, ADR 0022, `src/edit/`): `ContentOps::read_page(&cos_doc, cos_page, ContentOwner::Page(id))` or `from_parts(owner, [(Option<ObjRef>, bytes)], &limits)` joins the parts with `\n` as `page_content` does (`ContentPart` ranges in `source()`), tokenizes them into `ContentOp`s (operands, keyword, `span` from the previous operator's end through the keyword or `EI`, which `InlineImage::end` gives) and groups them into `ContentObject`s (`ContentObjectKind::{Text, Path, Image, Form, XObject, Shading}`, operator ranges, `marked` indices into `MarkedSequence`s with their inline `/MCID`), within `max_content_operators`; `ops.recorder(page_frame)` is a `Visitor` (`Recorder`) for `interpret_page` that records each object's `GraphicsState` before its first operator (the new defaulted `Visitor::operator_state`), resolves `Do` to `Image` or `Form`, and boxes what it paints in page space (text from `Visitor::shown_text`'s advance: `TextExtractor::page_with` forwards `operator`, `operator_state` and `shown_text`, so passing the recorder there gives text its measured width; alone, text has no width); `hit_test(PointPt)` (2 pt slop) and `hit_test_rect(&RectPt)`, topmost first; `ContentObjectId` per IR, `reference(id)` → `ContentObjectRef { owner, ordinal, hash }` (`source_hash`: FNV-1a 64 of the object's bytes from its first token, or of its canonical form once edited) and `find(&ref)` (`None` when stale: the ops' `content-object-stale`); `replace(id, Vec<ContentOp::new(operator, operands)>)` and `remove(id)` keep IDs and indices in step and drop marked content wholly inside; `encode()` → `EncodedContent { parts: [EncodedPart::{Unchanged, Written}] }` writes each part an edit touched, copying the source but the dropped tokens and writing new operators canonically at their anchor (each part on its own, since the parts concatenate), and `encode_every_part()` writes them all. `NotEditable` names `content-not-editable`'s reasons (`laminapdf_ops::Error::ContentNotEditable`; `ContentObjectStale { ordinal }`). Tests: `src/edit/tests.rs`, `tests/ir.rs` (every fixture page written back byte for byte), `laminapdf-text`'s `tests/content_ops.rs`; the `content_ir` fuzz target (`tests/common/ir_fuzz_entry.rs`); `benches/ir.rs` in `cargo xtask bench`.

Editing API (ADR 0005 §3, 0006): the base bytes never change; every write goes through `laminapdf_cos::Document::edit()` → `CosMut` into the overlay (resolution reads it first; an entry equal to the base is dropped; `is_dirty()`), with a journal (`journal_mark`, `rollback_to`, `take_changes`). `laminapdf_ops::Document` wraps the model document and is the only write path for callers: `doc.transact(Origin::Local, |tx| { tx.apply(op)?; … })`, `tx.savepoint(…)`, or `begin`/`apply`/`commit`/`rollback`; `undo()`/`redo()` return `UndoOutcome::{Applied, Partial, Skipped}`. Ops (`SetMetadata`, `RemoveMetadata`, `SetXmpProperty`, `RemoveXmpProperty`, `ReplaceXmpPacket`, `RotatePage`, the outline ops `AddOutlineItem`, `UpdateOutlineItem`, `MoveOutlineItem`, `DeleteOutlineItem` and the named-destination ops `SetNamedDestination`, `RenameNamedDestination`, `DeleteNamedDestination` (E3b, `src/outline/`: lists kept whole through `OutlineTree`, a name kept in the store it was found in, web addresses only `http`, `https` or `mailto` (`link-uri-refused`); `Applied::created_outline_items`, `outline_repaired`, `destination_uses`), `SetPageLabels` (E2q, `labels.rs`: the whole `/PageLabels` tree from `PageLabelRange`s, each from a `PageId` with the model's `LabelStyle` by name, prefix and first number; `invalid-label-ranges` with `what` `first-page`, `order` or `first-number`; no write when the catalog already holds exactly these labels (`PageLabels::is_written`, read without warnings); `first` a `u32`), `SetInitialView` (E3d, `src/initial_view.rs`: class `Document`; `open` as `OpenAt { page, zoom: OpenZoom }`, `page_mode`, `page_layout` and a `WindowPreferencesPatch`, each absent/`null`/value; an `/OpenAction` that is another action is `open-action-not-destination`; a newer value raises `/Version`; its arguments read through one `serde_json::Value` path for the WASM budget), and `SetInfo`, deprecated but kept on the wire; `UpdateSaveMetadata` is the save planner's alone and never serialised) are serde JSON (`{ "op": "rotatePage", "args": { … } }`, envelope `OpLog { v: 1, ops }`), with frozen samples in `fixtures/ops/v1/`. The metadata ops (E1c, `src/metadata/`) all go through one writer over `xmp::MAPPINGS`: the same value to Info and XMP (authors joined with `; ` in `/Author`, a Seq in `dc:creator`; characters XML can't hold dropped from both), a missing packet created from `Packet::new_minimal()` seeded with Info's values, a malformed one replaced only with `replace_malformed` (else `malformed-xmp`), the stream unfiltered, and in PDF 2.0 (`laminapdf_model::Document::is_pdf2`) only the two dates written to Info; `SetInfo` (`#[deprecated]`) keeps an existing packet in step and adds none before PDF 2.0; in PDF 2.0 it follows the same rule as `SetMetadata`. `Applied::packet_rewritten` (`Written::canonical`) and `still_in_earlier_revisions` report what an op did. The XMP ops (E3e, `src/metadata/xmp.rs`) edit any property (`XmpValue`: text, URI, integer, real, boolean, date, `langAlt`, `seq`/`bag` of simple values; `{ type, value }` on the wire) or the whole packet: a property `MAPPINGS` lists goes through the same writer, so Info stays in step (a value of the wrong shape is `invalid-xmp-property`, reason `shape`); `pdfaid:`/`pdfuaid:` are refused (`xmp-claim-read-only`), also in a replaced packet, which is parsed first (`invalid-xmp-packet`, `reason`, `offset`) and brings Info's mirrored entries into step; in a packet that claims PDF/A, `xmp::Packet` declares each property outside the predefined schemas in `pdfaExtension:schemas` (`Written::declared`, `Applied::declared`, the façade's `Edited::declared`); `Document::xmp_packet` (`XmpText`, TS `xmpPacket()`) reads the packet's XML. `read_metadata` → `DocumentMetadata` (XMP wins in PDF 2.0 and PDF/A files, else the newer modification date, Info on a tie; `disagreements`, `packet`, `pdfa`, `pdfua`, `kept_info_keys`); `conformance_warnings` → `ConformanceWarning` (`pdfa-one-author`, `pdfua-title-missing`, `pdfa-info-mismatch`: `opWarnings` in `codes.json`). The page ops' foundation is in `laminapdf-model` (E2j), behind its default feature `edit` (the workspace's dependency on the crate turns default features off, so crates that only read, the WASM modules among them, compile none of it; its parts `navigation`, the outline editor `OutlineTree`, and `tree-write`, the tree writers, `set_catalog_entry` and `PageLabels::write`, are features of their own, `navigation` including `tree-write`, and `laminapdf-ops` turns on the whole `edit`): `doc.edit_page_tree()` → `PageTreeEditor` (`insert`/`insert_new`/`remove`/`move_pages` by `PageId` and `PagePosition::{Start, End, Before, After}`, then `finish`; a moved page keeps the inherited `/Resources`, `/MediaBox`, `/CropBox`, `/Rotate` it showed, touched `/Count`s and `/Parent`s are written, empty nodes removed, the tree rebuilt balanced only past `MAX_DEPTH` 32 or a touched node over `MAX_KIDS` 1,024, a page listed twice copied with `invalid-entry` (`Kids`)); `TreeWriter::write_names`/`write_numbers` (fresh balanced trees, `/Limits`, at most `with_max_kids` per node, default 64); `PageLabels::remap(before, after)` and `write`; `doc.page_references(pages)` → `PageReferences` (`ReferenceKind::{OutlineItem, Link, NamedDestination, OpenAction, StructElem, StructContentRef, Widget}`, `Via::{Dest, GoTo}`); fixtures in `fixtures/pages/` (`make.py`, no dependencies). Saving API (ADR 0007, ADR 0005 §3; `laminapdf-save`): the `Save` trait on `laminapdf_ops::Document`: `doc.plan(&options)`, `doc.save(&mut sink, &options)` (write-only sink: a full rewrite leaves `SaveState::SavedNotRebased` until `doc.rebase(bytes)`) and `doc.save_and_rebase(sink, &options)` (a `ReadableSink`). Every save plans first: `SavePlanner::new(&doc)` detects the `SaveConstraint` (signatures from signature fields, `/Perms` DocMDP/UR3, `/Reference` transforms, `/Lock`, DocTimeStamp, and a repaired file's objects; `doc_mdp`; rewrite reasons `RepairedBase`, `EncryptedBase`, `NoBase`, `OpRequiresRewrite`; `signatures_unknown` when part of the form can't be followed (counts as signed); violations of the pending op classes, `laminapdf_ops::Document::pending_changes()`, and, field by field (E2r, ADR 0007 §11), of the widgets page ops deleted or reshowed (`PendingChanges::widgets()`, `Applied::widgets`: `TouchedWidget { field, change: WidgetChange::{Deleted, Reshown, Moved}, class }`; `Restriction::SignedWidget` for a signed signature field's widget, `Restriction::FieldMdp` for a locked field's, by the lock's `/Action` and `/Fields`, with `Violation::field`; the planner indexes each page's `/Annots` widgets only when a signature has a field or a lock; `would_violate` reads `Op::page_changes()`; `laminapdf_ops::test_support::Declared`, feature `test-support`, declares widgets for the tests; `laminapdf-save`'s `page-checks` feature, on by default and in the façade's defaults (`laminapdf/page-checks`), the CLI and the desktop engine, off in the WASM modules until they ship a page op)), `kind()` is `Free | AppendOnly | RequiresRewrite | Conflict`, and `SaveMode::{Auto (default), Incremental, FullRewrite}` is resolved per ADR 0007 §3; refusals are `would-invalidate-signatures` (the whole constraint), `requires-rewrite` and `encrypted-base` (every mode, unless `with_remove_encryption(true)`: a plaintext full rewrite); an unchanged document always saves incrementally (the base bytes unchanged). `with_invalidate_signatures(true)` is the explicit override (the writers write the output with the invalidated `/V` and `/Perms` entries removed, listed in `SaveReport::invalidated`; the document changes only through the rebase); `planner.would_violate(&op)` checks an edit early; `planner.conformance_warnings()` lists the PDF/A and PDF/UA claims the edited metadata breaks (never blocking). Save-time metadata (E1c): `SaveOptions::with_metadata_date(PdfDate)` / `with_instance_id([u8; 16])` make `plan` decide `MetadataUpdate::Stamp` for a dirty document unless the stamp (class `Metadata`) adds a violation the pending changes don't have (then `Skipped` and `SaveReport::metadata_not_updated`); a stamped save applies `UpdateSaveMetadata` (`xmp:MetadataDate`, `xmp:ModifyDate`, `/ModDate`, `xmpMM:InstanceID`, derived from a SHA-256 of `/ID[0]`, the overlay and the trailer without an ID) in an `Origin::System` transaction left open while the writer runs, committed after it, rolled back on failure; existing packets only; default options stamp nothing, so a shell passes the save time. `SaveReport::metadata_updated` (true only when the stamp changed something), `packet_rewritten`. `IncrementalWriter` / `FullWriter` over a `laminapdf_cos::Document` stream to a `WriteSink` (`Vec<u8>`, `IoWrite<W>`; append only). A failed save leaves the document `Dirty`; a failed rebase after a complete write returns `SaveError::NotRebased` with the output; undo history survives only an incremental save that freed nothing. `SaveOptions` (`mode`, overrides, `IncrementalOutput`, `Renumber::{Keep, Compact}`, `XrefKind::{Stream, Classic}`, `XrefEol`), `SaveReport`. `/ID[0]` is kept, `/ID[1]` is a content hash; output is byte-deterministic. The spike-era `Writer` / `incremental_update` build test files from scratch, on the same xref and object-stream helpers as the two writers (Q2d); they are `laminapdf_save::test_support`, behind the off-by-default `test-support` feature that every crate's path-only dev-dependency on `laminapdf-save` (and the fuzz workspace) turns on.

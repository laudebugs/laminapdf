# WebAssembly and TypeScript

`laminapdf-wasm` (`@laminapdf/wasm`), `@laminapdf/sdk`, its worker client and `@laminapdf/viewer`.

WASM (ADR 0002, 0016; `laminapdf-wasm`, B6a): one crate built three times by `cargo xtask wasm` into `packages/wasm/dist/` (`@laminapdf/wasm`): `lamina_pdf_base` (`WasmDocument`: `openBytes`, `pageCount`, `pageInfo`, `page` → `WasmPage` by ID, `info`, `warnings` → cursor, `isEncrypted`, `apply(ops)` → `{ touchedPages, changed }`, `applyLog`, `undo`, `redo` → `{ outcome, touchedPages }` (E1d), `metadata`, `plan(options)` → `PlannedSaveJs` and `wouldViolate(op)` (E1c, `src/plan.rs`), `save` → `{ bytes, report }` (`SaveOptionsInit` takes `metadataDate`, a PDF or ISO 8601 date, and `instanceId`, a UUID), `saveJob` → `WasmSaveJob.step(budget)`; `WasmBuilder` → `page(w, h)` → owned `WasmPageBuilder` (flat `Float64Array` paths, colour component arrays, `image`, `link`, `beginTag`/`beginArtifact`/`endTag` with flat arguments: structure type, scope and artifact kind by name, from the tables `cargo xtask gen boundary` copies into `@laminapdf/sdk`) → `finish()`; navigation and metadata records) and `lamina_pdf_text` (a superset: `fontBytes`, `fontCollection`, `standardFont`, `text`, `textBox`, `markdown` (T4i: `WasmMarkdownOptions` holds the fonts by role and images by target, a record the size, contents levels and page template), `flow(document, resources, options)` (T4j, `src/builder/flow.rs`: a `laminapdf.document/1` document as JSON, filled from `options.data` when given; `WasmFlowResources` holds the fonts and images by name; returns the page IDs), and `WasmPage.text`), and `lamina_pdf_extract` (base plus `WasmPage.text` and, in it and the text module, `WasmDocument.extract(options)` (L3e, `src/extract.rs`): one string per `format`, Markdown, text, the `laminapdf.extract/1` JSON or the chunks as a JSON array; `WasmDocument.extractJob(options)` (L3c) → `WasmExtractJob` for models the host runs (`options.models`): `step(budget)` → progress with `request` (`{ kind: "layout" | "ocr", page, dpi, langs }`) or `{ state: "done", output }`, `provide({ kind, regions | words })` with `[x, y, w, h]` boxes, `cancel()`; `@laminapdf/sdk`'s `doc.extractJob` wraps it (L3h); B9c: a struct of arrays: lines, runs as records, quads in one `Float32Array`, glyph text with UTF-16 offsets; budgets in ADR 0016 §6). Records are JSON-shaped objects with tsify `.d.ts` types (unknown keys: `unknown-option`); errors are thrown as the ADR 0026 object (`bindingErrors` in `codes.json`). `WasmPage` and `WasmSaveJob` hold their document weakly (`disposed` once it is freed). Memory (ADR 0016 §8, L2b): a 2 GiB maximum linked into each module; `allocationFailed()` (a recording global allocator in `src/memory.rs`) tells an out-of-memory trap from another; `__wbg_reset_state` replaces an instance; a 64 MiB build for the SDK's out-of-memory test, never shipped. Budgets per module (gzip) in `packages/wasm/size-budgets.json`, checked by `cargo xtask size`.

TypeScript (ADR 0016, 0026; `@laminapdf/sdk`, B6b): `await init(input?)` (URL, `Response`, bytes or `WebAssembly.Module`, handed to the glue's own loader; `{ module, text, extract }`; idempotent, a different source later is `already-initialized`) loads the base module, `init({ text: true })`/`loadText()` the text module, `init({ extract: true })`/`loadExtract()` the extract module; then everything is synchronous; documents open in the richest module loaded (text, extract, base). Export conditions `workerd` (static `.wasm` imports), `deno`/`browser`/`default` (the glue's `new URL(…, import.meta.url)`), `node` (bytes read from `@laminapdf/wasm`); exclude the package from Vite's pre-bundling. `Document.open(bytes, { password, strict, limits })` (the password as given, then its NFKC form after `wrong-password`), `await Document.openRange(source, options)` over a `RangeSource` (`httpRangeSource(url)`: tail-first `Range` requests, `If-Range`/`ETag` checks → `source-changed`, a `200` answer read whole, `fetch-failed`; `callbackSource(size, read)`) with `await doc.ensure(() => …)` for calls that throw `data-pending` (`LaminaPdfError.ranges`), `pages`, `info`, `warnings`, `page(i).text(options)` → `PageText` (`lines`, `text()`, `runs` with `glyphs()` and quads, `buffers`; `extract-module-not-loaded` for a document opened in base, `doc.canExtractText`; snapshot `fixtures/text/page-text.json` shared with Rust), `doc.extract({ format, pages, readingOrder, drop: { keepSpans, furniture }, tables, dehyphenate, pageMarkers, chunk })` (L3e, `src/extract.ts`: a string for `"markdown"`/`"text"`, an `Extraction` for `"json"`, `Chunk[]` for `"chunks"`; the JSON's types in `src/generated/extract.ts`, written by `cargo xtask gen boundary` from `crates/laminapdf-extract/schemas/extract.schema.json`; the JSON byte for byte the goldens `fixtures/extract/json/` that `crates/laminapdf/tests/extract.rs` writes), `doc.extractJob({ …, models: { layout?, ocr?, dpi?, langs? } })` (L3h, `src/extract-job.ts`) → `ExtractJob` (a handle freed with its document: `step(budget)` → progress with `request` or `{ state: "done", output }` parsed for the format, `provide({ kind, regions | words })`, `cancel()`; the model types are the binding's tsify ones) and `await extractWithModels(doc, options, { layout?, ocr? }, { signal, budget })`, which awaits the host's model per request (`invalid-argument` for a named model without a function), `doc.initialView()`, `doc.threads()` and `doc.setInitialView(patch)` (E3d; the extract or text module for the reads), `doc.metadata()`, `doc.setMetadata(patch, { at, replaceMalformed })`, `doc.removeMetadata(keys)`, `doc.plan(options)` and `doc.wouldViolate(op)` (E1c; served by the worker client too), `apply`, `applyLog`, `transact(tx => …)` (synchronous; collects ops, applies them as one transaction when the callback returns; other edits and saves of the same document inside it are `nested-transaction`), `undo`/`redo`, `save`/`saveWithReport`/`saveJob`, `free`/`Symbol.dispose`; handles (L2b, `src/internal/handle.ts`: `Document`, `PageRef`, `SaveJob`, `Builder`, `Page`, `Image`) free with `free()` or `using` (also under `Symbol.for("Symbol.dispose")`), a second free is a no-op, any later call `disposed`, a page or save job freed with its document; every glue call goes through `Instance.call` (`src/internal/instance.ts`): a trap throws `wasm-trap` or `out-of-memory` and the next call replaces the instance, `reset()` replaces every one, older handles throw `instance-reset`; `onLeak(hook)` reports handles collected without a free; `new Builder(options)` (in the text module when it is loaded) → `page(size)` → `surface()` (paths via `path(p => …)` → `fill`/`stroke`/`clip`, colours as `[g]`/`[r,g,b]`/`[c,m,y,k]`/hex, `Matrix`, `image(image, rect, alt?)`, `link`, `text`, `textBox`; tagged PDF: `tagged: true`, `tag(tag, s => …)`, `artifact(kind, s => …)`, a `tag` option on `text`/`textBox`; `TagName`, `TagSpec`) → `page.finish()` → `finish()` → `Document`; `Font.fromBytes`/`Font.fromCollection(bytes, index)`/`Font.standard`, `Image.jpeg`/`png`/`rgba`; `builder.markdown(text, { fonts, images, size, contents, page })` (T4i: fonts by role as `Font`s, images by the target the Markdown writes, `page` a template with size, margins, header, footer and furniture size; text module); `builder.flow(document, { data, fonts, images })` (T4j: a `FlowDocument`, or a `FlowTemplate` filled from `data`, typed by `src/generated/document.ts`, which `cargo xtask gen boundary` writes from `crates/laminapdf-build/schemas/document.schema.json`; the document's `profiles` go in the Builder's options; text module). Errors are `LaminaPdfError<C extends ErrorCode>` (ADR 0026 §1 fields, `toJSON`, `isLaminaPdfError(e, code)` narrows `code`; warnings are `LaminaPdfWarning`, typed by `WarningCode`); the unions and tables are generated into `src/generated/codes.ts`; `@laminapdf/sdk/explain` (a separate subpath, out of the main bundle) has `explain(code)`, `KINDS`, `HINTS`, `docsUrl`; `schemas/error.schema.json` is `laminapdf.error/1`; its own codes are `packageErrors` in `codes.json` (`already-initialized`, `not-initialized`, `text-module-not-loaded`, `extract-module-not-loaded`, `wasm-trap`, `out-of-memory`, `instance-reset`, …; left out of the Rust `ErrorCode` and the WASM; it raises `disposed`, a binding code, too). The JS (glues + API, min+gzip) has a 20 KB budget (`packages` in `size-budgets.json`). Worker client (L2a): `@laminapdf/sdk/worker`'s `await connect({ worker?, signal?, init? })` starts `dist/worker/entry.js` (the literal `new Worker(new URL(…, import.meta.url))`) and checks a `PROTOCOL_VERSION` + package-version handshake (`worker-version-mismatch`); `client.open(bytes, { transfer? })` / `openUrl(url)` return a `RemoteDocument` whose members are the sync ones as async methods (getters too: `await doc.pageCount()`; `page()` → `RemotePage`; `transact`, `saveJob`, `ensure`, `free` and the Builder not served, listed in `src/worker/support.ts`, which `tsc` keeps exhaustive), with per-call `{ signal, onProgress }` (`cancelled` with `cause`; `save` is stepped in the worker and stops at the next step), transferred outputs, rebuilt `LaminaPdfError`s, `worker-crashed` + `on("crashed")` + `restart()`, `close()`/`Symbol.asyncDispose`; the client and worker file have their own budgets. Extensions (C3a): `@laminapdf/sdk/worker/server`'s `serve({ methods })` adds methods to the same worker (an extension method's `reply` builds each coalesced caller's answer), called with `client.request(method, params, { priority, key })`; the queue reads every pending message before each call, runs the highest priority first and coalesces equal keys; `emit()` → `on("event")`; `connect({ onDiscard })` closes late answers' `ImageBitmap`s. Viewer (C3a, `@laminapdf/viewer`): `await ViewerClient.create({ backend: { backend: "pdfium", wasm } })` starts one document worker and loads the backend; `open(blob | bytes, { password, limits, renderLimits })` → page count and sizes; `render(request, { priority: "visible" | "prefetch" | "background", signal })` → a transferred `ImageBitmap` (aborts reject with `AbortError`, late bitmaps closed); events `warning`, `render-start`, `render-slow` (soft 10 s), `render-stuck` (encrypted, hard 120 s), `crashed`, `restarted`, `password-required`; `stop()` terminates and restarts; the password is posted once and kept only in the worker. A document opened in the base module (before the extract module loaded) reads its text from a copy the worker opens from the same bytes (`src/worker/document.ts`: `textModel`, `Open.text`), which makes every edit, undo, redo and adopted save after the model from `EditState.log`; `client.editInTextCopy({ text })` (E4l) makes that copy the model, in the text module when `text` is set (fonts by their bytes, fallbacks), so the document takes text boxes with its history kept, and a restarted worker does it again; the log stays from the open while a copy may yet open from the file (any document not in the text module and not encrypted), each adopted save's bytes with it, until a save that rewrote the file (`historyCleared`) makes those bytes the file a copy opens from (`rebaseReopen`). `Document.hasText` says whether a document is in the text module. `client.soundAsWav(id)` (E5h) reads a sound comment's recording as WAV in the worker, for an `<audio>` element. `client.commentThreads()` (E5g) reads the document's comments as threads in the worker, for the reader's Comments panel. `viewer.adoptTouch(down)` (E4k) hands a touch a tool took back to the gestures, and the gestures skip a pointer a tool took or swallowed first (`preventDefault`; `attachTools` listens in the capture phase). `placeBox(box, points, size, rotation)` sizes a page layer's box in points and turns it to the page, as the viewer's own layers place theirs; the reader's text-box editor (E4j) uses it. Runtime matrix (B6c): `test/suite/examples.ts` is the one example list (the six Rust twins and the 100-page `report`, checked by `REPORT_SHA256`); each runner (Node, browsers, Deno, Bun: `runSuite(runtime, read, register)`; workerd: a Worker bundling `INPUT_PATHS`) supplies the fixtures its own way and prints `LAMINA_PDF_MEASUREMENT {json}` lines that `cargo xtask pdf-runtimes` collects; `measure()` runs first in a fresh module instance (Node: the `measure` project of `vitest.node.config.ts`, which `cargo xtask wasm` leaves out; workerd: `scheduler.wait(0)` between clock readings, since its clock only moves across I/O). workerd runs through wrangler's `createTestHarness` from Node (`@cloudflare/vitest-pool-workers` supports Vitest 4 only). The viewer (C3b): `createViewer({ client, margin?, gap?, pool?, cacheBytes?, settleMs?, zoom? })` → `mount(container)`, `open(await client.open(file))`; a prefix-sum `PageLayout` (one column, `pageAt` by binary search) mounts page shells for the visible range ± a margin (2 pages or one viewport), each with a pooled canvas (`CanvasPool`: 12, 40 MP; at most 8 MP per page, else a backdrop under a detail canvas over the part in view at the full pixel ratio, from a second pool of 3, 24 MP; C3d) painted by a low-resolution pass then 512-CSS-px sharp tiles (`tilesFor`), bitmaps in a 256 MB farthest-first `BitmapCache`; a shell leaving the margin aborts its renders and a late result is never drawn; zoom modes `fit-width`/`fit-page`/`actual-size`/10–800 % from ctrl+wheel, pinch, Safari gestures and `+`/`-`/`0` keep the point under the cursor (sharp re-render after 150 ms); `rotate`, `goToPage`, `getState`/`subscribe`, `pagechange`/`zoomchange`/`renderstats` events, `addLayer` into the `text`/`annot`/`highlight` slots; a document taller than 16 M CSS px gets its zoom capped. Copy and selection (U2a): copy as paragraph (the default; `layers/copy.ts`: the selection's pieces ordered by the page's reading-order blocks from the worker's `readingOrder` method, lines joined, hyphenated words joined again, ligatures expanded, a blank line between blocks, tables kept line by line) or exact (the layout's lines), both written as `text/plain` and `text/html`; `copySelection(mode)`, `columnSelect` and Alt/Option-drag column selection (the runs whose centre is in the rectangle, tinted by the layer); the `selectionchange` event and `onSelection` with `settled` (pointer up) and `column`; `@laminapdf/ui`'s `SelectionActionBar` (touch) and `selectionBox` (the toolbar's anchor); the web app shows `SelectionToolbar` on a settled mouse or pen selection and the bar on a touch one (`apps/web/src/selection.tsx`).

Form behaviour (E8f; extract and text modules, `crates/laminapdf-wasm/src/form_behaviour.rs`): `doc.fieldBehaviour(id)` → `FieldBehaviour` (`keystroke`, `format`, `validate`, `calculate` as `FieldHelper`s tagged `number`, `percent`, `date`, `time`, `special`, `range`, `calculate`; `notHandled` as `/AA` keys), `doc.validateField(id, text)` → `FieldCheck { value?, refused?: "format" | "range", shown, red }`, `doc.fieldAccepts(id, text)` → `boolean`, `doc.calculate()` → `Edited` (`skippedCalculations`), `doc.formScripts()` → `FormScript[]` (`owner`, `page?`, `name?`, `trigger?`, `object?`, `bytes`, `state`); the `setFieldHidden` op crosses through `apply` in every module.

Comment interchange (E5d; extract and text modules, `crates/laminapdf-wasm/src/interchange.rs`): `doc.exportAnnotations({ format: "xfdf" | "fdf" | "markdown", pages?, comments?: "all" | "highlightsAndNotes", file?, markdown?: { headings?, authors?, replies? } })` → `Uint8Array`; `doc.previewImport(bytes, { mode?, file? })` → `ImportSummary` (`added`, `matched`, `deleted`, `pages`, `warnings`: `interchange-skipped` with `kind`, `reason`, `page`, `line`, or `interchange-document-mismatch` with `file`); `doc.importAnnotations(bytes, options)` → `{ summary, edited }`, one undo step. A file that doesn't read throws `interchange-malformed` with `data: { format, line }`, or `interchange-dtd`, `interchange-unknown-format`, `interchange-too-large`.

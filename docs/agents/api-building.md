# Building

The Rust API of `laminapdf-build`: pages, text, tagging, conformance profiles, flowing layout, Markdown and JSON documents.

Building API (ADR 0005 §6, ADR 0027; `laminapdf-build`, B5a, B5b): `Builder::new(BuildOptions)` (version, fixed `/ID[0]`, `/Producer` and `/CreationDate` given, never read from a clock) → `page(PageSize)` (`rotate`, `user_unit`, `crop_box`/`bleed_box`/`trim_box`/`art_box`) → `surface()` → `PageBuilder::finish()` → `Builder::finish()` returns a `laminapdf_ops::Document` over an empty base (`laminapdf_cos::Document::empty`; saving is a full rewrite); `Builder::on(&mut laminapdf_model::Document, &BuildOptions)` appends pages to an open document (save with `IncrementalWriter`); features newer than the version raise the catalog's `/Version`. The `Surface` takes page space only (`Pt`, `PointPt`, `RectPt` from `laminapdf-model`: top-left of the displayed CropBox, y down, `/UserUnit` applied; raw user space is `UserSpacePoint`/`UserSpaceRect` and `PageFrame::to_page`/`to_user_space`, computed once per page by `Page::frame()` with the US Letter fallback) and writes `pdf_writer::Content`: paths (`path(|p| …)` returns a `PendingPath` painted with `fill`/`stroke`/`fill_stroke`/`clip`; invalid values fail `PageBuilder::finish` with `invalid-geometry`), `StrokeStyle`, `FillRule`, clip, `Color` (gray/RGB/CMYK/hex, `IccProfile`), `opacity`/`BlendMode`, `Image` (JPEG pass-through with the Adobe CMYK `/Decode`, PNG with `/SMask`, raw RGBA). Text (B5b): `Builder::font(laminapdf_text::Font)`/`font_with`/`standard_font(Standard14)` give a `FontHandle` (one `FontRegistry` per build, subset at `Builder::finish`); `surface.text(str, &font, size, at)` with **`at.y` the baseline** (shaped, bidi, `/ActualText`; standard 14 laid out unshaped with AFM widths) returns a `TextRun` (`fill`, `render_mode`, `features`, `link`, `bounds`); `surface.text_box(str, &font, size, rect, &TextBoxOptions)` → `TextLayout` (line boxes, `overflow`; `Overflow::Error` is `text-overflow`), and `surface.measure_text_box(…)` the same layout without drawing (T4f). Links: `surface.link(rect, LinkTarget::{Uri, Page { index, fit: Fit }, Named}, contents)`, targets resolved at finish (`page-index-out-of-range`, `unknown-destination`). Document: `destination(name, index, fit)` (`/Names /Dests`), `outline([OutlineEntry])` (returns `OutlineItemId`s), `page_labels([PageLabel])` (`invalid-page-labels`), `metadata(Metadata)` (Info and an XMP packet from the same values, each property the element `laminapdf_model::xmp::property_element` writes for its row of the shared `MAPPINGS`, which a unit test holds it to; spelled out rather than built from the table at run time for the WebAssembly budget), `lang`, `viewer_preferences`. Resources are named per page in order of first use (`GS1`, `CS1`, `Im1`, `F1`) and written once per document. Its codes are `buildErrors` in `fixtures/codes.json`; Tagged PDF (B8a, `src/tag/`): `BuildOptions::with_tagged(true)` or any page using an element makes the document tagged (`/MarkInfo`, `/StructTreeRoot` with one `Document` element); `surface.tag(impl Into<Tag>, |s| …)` (closure returns `Result`), `TextRun::tag`, `surface.figure(&image, rect, alt)`, `surface.artifact(impl Into<Artifact>, |s| …)` (an `ArtifactKind`, or `Artifact::header()`/`footer()`/`watermark()` with `/Subtype` and `/Attached`, `with_attached(&[PageEdge])`; T4f), `begin_tag`/`begin_artifact`/`end_tag` for bindings; `Tag::new(TagKind)` / `Tag::custom(name, role)` (`RoleMap`) with `/Alt`, `/ActualText`, `/E`, `/Lang`, `TableScope`; MCIDs per page (`/<Tag> <</MCID n>> BDC … EMC`, closed before `q`/`Q` and element boundaries), `/StructParents`, links as `Link` elements with `OBJR` and `/StructParent`, `/Tabs /S`, one-leaf `ParentTree`; elements across pages (T4f, `src/tag/open.rs`): `surface.open_element(tag)` → `ElementId`, `surface.resume(id, |s| …)` on that page or later ones, `Builder::close_element(id)` (kids on later pages are `MCR`/`OBJR` with their own `/Pg`; `tag-element-unclosed` at finish, `tag-element-not-open`); appended pages are never tagged; `Builder::tagging_diagnostics()` → `TagDiagnostic::{Untagged, MissingAlt}` (untagged drawings and link annotations per page, also from pages finished before tagging began; no codes; the profiles decide); custom names that are standard types are never role-mapped; `/Tabs /S` and `/E` raise the version to 1.5. `laminapdf-model`'s `Document::structure()` → `StructTree` (read-only: kinds, attributes, MCIDs, `OBJR`s, `RoleMap`, raw `ParentTree`). Conformance (B8b, `src/profile/`): `BuildOptions::with_profile(Profile::{PdfUa1, PdfA2b, PdfA2u, PdfA3b, None})` (UA-1 plus at most one PDF/A; UA-1 tags the document; TS `profiles: ["PDF/UA-1", …]`) makes `Builder::finish` check, before writing, the machine-checkable rules the builder could break and fail with the first: `missing-title`, `missing-lang`, `untagged-content`, `missing-alt-text`, `heading-level-skipped`, `unnumbered-heading-misused`, `invalid-structure-nesting`, `link-without-structure`, `link-without-contents` (UA-1), `font-not-embedded` (standard 14), `glyph-without-unicode` (A-2u, UA-1; the empty value of a glyph whose cluster's text another glyph carries counts as one, which veraPDF accepts), `device-color-without-output-intent` (A: `DeviceCMYK`), `embedded-file-forbidden` (A-2), `embedded-file-without-mime-type` (A), `profile-version-conflict` (PDF 2.0); the Matterhorn conditions are named in `profile/checks.rs` and the tests. It always writes the XMP packet (`pdfaid`, `pdfuaid`, the `pdfuaid` extension schema when both), `/DisplayDocTitle` (UA-1) and for PDF/A a `GTS_PDFA1` output intent with the 480-byte CC0 `data/sRGB-v4.icc` (provenance in `data/README.md`). `Builder::attach(Attachment::new(name, bytes, mime).with_relationship(AfRelationship::…))` → `/EmbeddedFiles` + catalog `/AF` (TS `attach(name, bytes, mime, { relationship })`). Flowing layout (T4b, ADR 0032, `src/flow/`, feature `text`): `Builder::flow(&Flow)` → `FlowReport { pages, warnings }`; `Flow` of `FlowBlock`s (`Paragraph` of `TextStyle` pieces, links and line breaks; `Heading`, `List`, `Figure`, `Spacer`, `PageBreak`, `Keep`, and (T4c) `Table` with `ColumnWidth::{Fixed, Fraction, Auto}` widths fixed for the whole table, header rows repeated on later pages as `Pagination` artifacts, rows kept whole, footer rows kept with the last row, cells with spans and alignment, rules and backgrounds as `Layout` artifacts, tagged `Table`/`THead`/`TBody`/`TFoot`/`TR`/`TH` (`/Scope /Column`)/`TD` (`/ColSpan`; new `TagKind`s and `Tag::with_col_span`); and (T4h) `Contents` (`TOC`/`TOCI`, leaders, page numbers, links)) through a `PageTemplate` (margins, header and footer `PageRegion` slots with `{page}`, `{pages}`, `{section}`, `{title}`, a first-page variant); lines broken by `break_spans` and drawn from that shaping; greedy pagination with widows and orphans, headings kept with the next block, keep chains moved once (`flow-keep-broken`, a `laminapdf_build::Warning` in the new `buildWarnings` group), `flow-content-too-large`; laid out before drawn, so `{pages}` is known; footnotes (T4h, `Paragraph::note`: a raised `Reference` marker, the `Note` body at the foot of the citing page; a line moves with notes that don't fit); a contents block lays the flow out again until its numbers settle, at most four times (`flow-layout-unstable`); a named destination per heading and an outline nested by level unless `Flow::with_outline(false)`; tagged by default, each paragraph one element across pages, header and footer `Pagination` artifacts with `/Subtype`; the façade's `laminapdf::flow`, `Builder::flow` and `Warning::Build`; the `flowing_report` and `flowing_invoice` examples and the `flowing` bench (`tests/common/spike_report.rs`). T4d adds `Inline::Code`, `TextStyle::with_strikethrough`, `List::with_start`, `ListItem::with_marker` and the blocks `Quote` (`TagKind::BlockQuote`), `CodeBlock` and `Rule`; and Markdown (`src/markdown/`, feature `markdown` over `pulldown-cmark`; the façade's `markdown` feature, on by default, with `laminapdf::markdown`): `Builder::markdown(&str, &MarkdownBuildOptions)` → `FlowReport`, CommonMark with tables, footnotes, strikethrough and task lists, `key: value` front matter into the metadata and `/Lang`, `#slug` links to the headings' destinations, images only from `MarkdownBuildOptions::with_image`, `MarkdownFonts` by role (Helvetica and Courier when none are given, which PDF/UA-1 refuses), raw HTML dropped with `markdown-html-ignored` and missing images with `markdown-image-missing` (`buildWarnings`, a byte `offset` in their data, never the Markdown's text); the `markdown_to_pdf` example over `fixtures/markdown/report.md`; `tests/markdown.rs` (a test per construct, reading back the structure tree). JSON documents (T4e, `src/flow/document/`, features `serde` (over `serde`, `serde_json` and `serde_path_to_error`) and `schema` (schemars); the façade's `document` feature, on by default, and in the WASM text module since T4j): `laminapdf.document/1` as its own serde types under `flow::document` (the only path; `FlowDocument`: title, lang, author, subject, `profiles` (`FlowDocument::profiles()` for the builder's options), `page` (size by name or points, margins, header/footer regions and their style), `outline`, `styles` (named `StyleSpec`s: a font by name, size, fallbacks, `#rrggbb` colour, language, strikethrough; `body` the default) and `blocks` tagged by `type` (paragraph, heading with `level`, list, figure, spacer, pageBreak, keep, table, contents, quote, codeBlock, rule; spans with style, `href`, code, line breaks, notes); `Text` takes strings, numbers or booleans); fonts and images by name from `flow::document::Resources` (`with_font`, `with_image`), else a standard 14 font by its PostScript name; `FlowDocument::from_json` (`invalid-document` with the value's JSON Pointer and `reason` in its data and `didYouMean` from serde's expected keys), `to_json`; `flow::document::fill(&template, &data)` (`$data`, `$each` over the data or `{ "$item": … }`, `$item`, `$if`; a placeholder object holds nothing else, `$each`/`$if` need `do`; `template-data-missing`, `template-data-type` (also a pointer that isn't one), each with the pointer and placeholder; `template-too-large` past 100,000 values or 64 levels), then the document check (`check.rs`: when serde's path stops at a `type`-tagged block, each block is read again kind by kind for the exact pointer; `didYouMean` only from the format's own keys, read after serde's last `, expected `; then heading levels 1–6 and sizes, widths and counts in range: `out-of-range`); `Builder::document(&doc, &resources)` lays it out and sets its title, author, subject and language; `flow::document::json_schema()`, committed as `crates/laminapdf-build/schemas/document.schema.json` (its GitHub URL as `$id`; the packages ship it in `docs/schemas/`), checked and every filled `fixtures/documents/` template validated by `tests/document_schema.rs`; the `invoice_from_json` example over `fixtures/documents/invoice.json` and `invoice-data.json` (two pages, PDF/UA-1); the `document` fuzz target (`tests/common/document_fuzz_entry.rs`, replayed by `tests/document_regressions.rs`). The CLI and MCP inputs are T4k's (`laminapdf build doc.json --data`, below). Goldens `vectors.pdf`, `images.pdf`, `build-text-latin.pdf`, `build-text-multiscript.pdf`, `links-and-outlines.pdf`, `metadata.pdf` (pypdf/pdf.js/pdftotext/qpdf facts in `fixtures/build/facts.json` from `tools/fixtures/build_facts.py`), `tagged-report.pdf` (pdf.js `getStructTree` and PDFium structure facts in `fixtures/build/structure.json` from `tools/fixtures/structure_facts.py`), `tagged-across-pages.pdf` (T4f: PDF/UA-1, a paragraph and a table across pages, footers with the footer subtype, Arabic with diacritics), `flow-table.pdf` (T4c: a 60-row flowing table over three pages under PDF/UA-1) (and the frozen `hello.pdf`, `imaging-demo.pdf`, rebuilt by its `tests/common/legacy.rs` with the spike's content builder) come from its `examples/golden.rs`.

Graphics

How lamina draws its windows on Linux. Change this only if windows are blank, flicker or lamina will not start.

Graphics
Uses your graphics card when it can. Fastest scrolling and zoom.
Turns off the faster renderer. Works with most drivers; scrolling may be slower.
Draws everything in software. Slowest, for when nothing else works.
Restart lamina after you change Graphics Your windows and tabs come back where you left them.

If lamina won’t open at all, start it from a terminal with lamina --safe-graphics once, then choose a setting here.

Printing

Prints through the built-in web view. Try it if a printer skips pages or prints them blank.

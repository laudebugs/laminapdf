# `encrypted-base`

- Type: error
- Kind: `unsupported` (valid input that lamina doesn't implement)

## What happened

An incremental update was requested for an encrypted document.

## Why

Encrypting new objects on save is not implemented yet.

## How to fix

Save with a full rewrite, or wait for encryption on save.

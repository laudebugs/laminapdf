# Todo board

One file per pull request of work. A todo lives in exactly one state folder:

| Folder | Meaning |
| --- | --- |
| [`ready/`](ready/) | Specified and waiting. Start one only when every todo in its **Depends on** is in `done/`. |
| [`ongoing/`](ongoing/) | Claimed: someone is working on it. Moved here by the first commit of its work PR, so `main` shows a todo here only once that PR merges; open PRs hold the current claims (`gh pr list`). |
| [`done/`](done/) | Merged. Moved here by the work PR before it merges. |

New todos start from [`TEMPLATE.md`](TEMPLATE.md). The workflow is in [git workflow §2](../guidelines/git-workflow.md#pick-work-from-the-todo-board); plans link to their todos. This board and every todo's **Blocks** field are generated by `cargo xtask todos` from the **Depends on** links; `cargo xtask check` fails when they are stale, and `cargo xtask docs-links` fails on any broken link.

IDs: `A`/`P`/`X` [architecture](../plans/architecture.md) (foundations, publishing, cross-cutting), `B` [library](../plans/pdf-library.md), `L` [shareable libraries](../plans/shareable-libraries.md) (contracts, worker, extraction, CLI, agent docs, mobile), `C` [web reader](../plans/web-app.md), `D` [desktop reader](../plans/desktop-app.md), `U` [UI/UX](../plans/ui-ux.md), `E` [editor](../plans/full-editor.md), `H` hosted service ([full-editor](../plans/full-editor.md)), `Q` [docs and code quality](../plans/quality.md). A letter suffix (`B2a`, `B2b`) splits a round into PRs.

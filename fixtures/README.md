# Fixtures

Shared test inputs and golden outputs, read by every implementation by path from the repository root ([code organization §6](../docs/guidelines/code-organization.md#6-tests-and-fixtures)). Today the Rust tests in `crates/lamina-cos/tests/` use them; future TypeScript and binding tests read the same files.

These files were moved here from the [`pdf-basics` spike](../spikes/pdf-basics/SPEC.md) in Round A. The spike keeps its own frozen copy in `spikes/pdf-basics/fixtures/`, so the two copies are identical today but only this one may change.

## Rules

- Every file is listed below with its origin, licence and what it exercises. A PDF without a known licence is not committed.
- `golden/` files are byte-exact expected outputs. Tests never rewrite them; a change is regenerated by an explicit command and reviewed like code.
- `corpus/expected.json` holds facts that every implementation must reproduce, extracted independently with pypdf, never by lamina (`page_count`, `encrypted`, `revisions` as the count of `%%EOF`, `has_xref_stream`, `first_page_mediabox`, `root_keys`, `header_version`, `size`, and `outline_titles` flattened depth-first). It is written by [`tools/corpus-facts/facts.py`](../tools/corpus-facts/facts.py) (`cargo xtask corpus facts`, with the pinned pypdf from its `requirements.txt` in `$LAMINA_PYTHON` or `python3`); the script reads and writes only `corpus/`. Deliberate differences go in `corpus/exceptions.toml`, each with the ADR 0003 rule behind lamina's answer.
- `differential/expected.json` holds pypdf's outcome (opened/repaired/failed), page count and outline titles for every corpus file and its fixed-seed mutants (generated by `crates/lamina-model/tests/common/mutants.rs`); `cargo xtask differential --update` regenerates it, and `crates/lamina-model/tests/differential.rs` compares lamina against it without Python. Triaged disagreements are in `differential/exceptions.toml`.
- `regressions/` (created with the first one) holds minimised fuzz crashes as `<target>-<hash>.pdf`, each with a named regression test ([`fuzz/README.md`](../fuzz/README.md)).
- Goldens are regenerated only by `cargo xtask golden --update`, which rebuilds every file in `golden/` from its source and prints the list; `cargo xtask golden` checks that nothing would change.
- `codes.json` lists every warning code, error code and hard-limit name that lamina exposes ([ADR 0003](../docs/decisions/0003-reader-tolerance-and-limits.md) §4). It is the single source of truth: `crates/lamina-cos/tests/codes.rs` checks the Rust enums against it, and the TypeScript package will too. Codes are never renamed or reused.
- Fixtures are data: Biome skips this folder, so files stay byte-for-byte as generated.

## Licence

Every file here was generated by lamina's own scripts, which are in the repository, and is licensed like the rest of lamina, `MIT OR Apache-2.0`. Where a file was written by a third-party library (pdf-lib, fpdf2, ReportLab, pypdf, pyHanko), the library only serialized content our script supplied; none of their code or assets are embedded, apart from the font subset noted for `text-example.pdf`.

## Files

The scripts behind the research-chapter files live in [`docs/research/pdf/examples/`](../docs/research/pdf/examples/README.md), where the same PDFs are also checked in next to them; fixtures written for lamina's own tests have their generators in [`tools/fixtures/`](../tools/fixtures/outline.py).

### `golden/`

| File | Origin | Exercises |
| --- | --- | --- |
| `hello.pdf` | `01-file-structure/hello.py` (no dependencies) | Byte-identical rebuild with the writer and content builder; `CrLf` xref entries; a hand-wrapped page dictionary (written as a raw body) |
| `imaging-demo.pdf` | `02-imaging-model/make_imaging_demo.py` (no dependencies) | Byte-identical rebuild; `SpaceLf` xref entries; per-operand number formatting in content streams |

### `corpus/`

| File | Origin | Exercises |
| --- | --- | --- |
| `hello.pdf` | `01-file-structure/hello.py` (same bytes as `golden/hello.pdf`) | A minimal classic file |
| `hello-broken.pdf` | `01-file-structure/variants.py`: `hello.pdf` with one wrong xref offset and a wrong `startxref` | Xref repair (`was_repaired`) |
| `hello-incremental.pdf` | `01-file-structure/variants.py`: `hello.pdf` plus one incremental update | Two revisions, `/Prev`; byte-exact output of `incremental_update` |
| `hello-xrefstm.pdf` | `01-file-structure/hello_xrefstm.py` (no dependencies) | Object stream + xref stream |
| `imaging-demo.pdf` | `02-imaging-model/make_imaging_demo.py` (same bytes as `golden/imaging-demo.pdf`) | Shading, ExtGState, content decoding |
| `text-example.pdf` | `03-text-and-fonts/make_text_example.py` (fontTools) | Type 0 / Identity-H font, ToUnicode, structure tree. Embeds a subset of **DejaVu Sans**, whose licence (Bitstream Vera / DejaVu font licence) allows redistribution of the font embedded in documents |
| `signed.pdf` | `04-signing-encryption/demo.py` (pypdf writes a blank page, pyHanko signs it) | PAdES-style signature added as an incremental update; 2 revisions. Signed with a throwaway self-signed test key that is not committed |
| `tampered.pdf` | `04-signing-encryption/demo.py`: `signed.pdf` with one byte changed | A damaged newest catalog that must repair to the intact older one |
| `enc.pdf` | `04-signing-encryption/` (pypdf, AES-256, `/V 5 /R 6`; listed with `demo.py` in [research ch. 04](../docs/research/pdf/04-interactive-security.md)) | `/Encrypt` detection (decryption is Round B2) |
| `raw.pdf` | `05-generation-approaches/raw_writer.py` (no dependencies) | Flate content, `/Length` before `/Filter`; reproduced by `tests/raw_writer.rs` |
| `pdflib.pdf` | `05-generation-approaches/pdflib_demo.mjs`, written by pdf-lib (MIT) | Object streams and xref stream from a third-party writer |
| `fpdf2.pdf` | `05-generation-approaches/fpdf2_demo.py`, written by fpdf2 (LGPL-3.0; only its output is committed, no fpdf2 code) | Classic file from a third-party writer |
| `reportlab.pdf` | `05-generation-approaches/reportlab_demo.py`, written by ReportLab (BSD-3-Clause) | `ASCII85Decode` content (an unsupported filter: only content decoding fails) |
| `outline.pdf` | [`tools/fixtures/outline.py`](../tools/fixtures/outline.py) (no dependencies) | Three-level outline (closed item, PDFDocEncoding and UTF-16BE titles, explicit, named and `GoTo` destinations), `/Names /Dests` and catalog `/Dests`, page labels, an Info dictionary with a valid and an invalid date |
| `expected.json` | pypdf over every corpus file ([`tools/corpus-facts/facts.py`](../tools/corpus-facts/facts.py)) | Facts checked by `crates/lamina-cos/tests/corpus.rs` and `crates/lamina-model/tests/corpus.rs` |
| `exceptions.toml` | hand-written | Deliberate differences from `expected.json`, each with its ADR 0003 rule (none today) |

### `differential/`

| File | Origin | Exercises |
| --- | --- | --- |

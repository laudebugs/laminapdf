# Fixtures

Shared test inputs and golden outputs, read by every implementation by path from the repository root ([code organization §6](../docs/guidelines/code-organization.md#6-tests-and-fixtures)). Today the Rust tests in `crates/lamina-cos/tests/` use them; future TypeScript and binding tests read the same files.

These files were moved here from the [`pdf-basics` spike](../spikes/pdf-basics/SPEC.md) in Round A. The spike keeps its own frozen copy in `spikes/pdf-basics/fixtures/`, so the two copies are identical today but only this one may change.

## Rules

- Every file is listed below with its origin, licence and what it exercises. A PDF without a known licence is not committed.
- `golden/` files are byte-exact expected outputs. Tests never rewrite them; a change is regenerated by an explicit command and reviewed like code.
- `corpus/expected.json` holds facts that every implementation must reproduce. It was extracted independently with pypdf (`page_count`, `encrypted`, `revisions` as the count of `%%EOF`, `has_xref_stream`, `first_page_mediabox`, `root_keys`, `header_version`, `size`).
- Fixtures are data: Biome skips this folder, so files stay byte-for-byte as generated.

## Licence

Every file here was generated by lamina's own scripts, which are in the repository, and is licensed like the rest of lamina, `MIT OR Apache-2.0`. Where a file was written by a third-party library (pdf-lib, fpdf2, ReportLab, pypdf, pyHanko), the library only serialized content our script supplied; none of their code or assets are embedded, apart from the font subset noted for `text-example.pdf`.

## Files

All scripts live in [`docs/research/pdf/examples/`](../docs/research/pdf/examples/README.md), where the same PDFs are also checked in next to them.

### `golden/`

| File | Origin | Exercises |
| --- | --- | --- |
| `hello.pdf` | `01-file-structure/hello.py` (no dependencies) | Byte-identical rebuild with the writer and content builder; `CrLf` xref entries; a hand-wrapped page dictionary (written as a raw body) |
| `imaging-demo.pdf` | `02-imaging-model/make_imaging_demo.py` (no dependencies) | Byte-identical rebuild; `SpaceLf` xref entries; per-operand number formatting in content streams |
